제목: What to Remember, What to Reveal: Privacy-Aware Memory for Conversational Agents

저자: Wenjie Wang, Wenhe Si, Xinyue Xu, Yue Xu

분야: 사이버보안 (cs.CR) / AI 에이전트 보안 · 개인정보 보호 · LLM 메모리

게시일: 2026-08-17

연구 배경

장기 메모리(long-term memory)는 대화형 에이전트가 세션을 넘어 사용자 정보를 유지해 개인화된 서비스를 제공하게 해주는 핵심 기능이다. 그러나 기존 메모리 아키텍처는 주로 유용성(utility)만 최적화하고, PII(개인식별정보) 같은 민감 속성을 불필요하게 저장·재사용하는 프라이버시 위험을 간과해 왔다. 단순히 민감 값을 삭제하면 개인화 성능이 무너지기 때문에, 프라이버시 보호는 개별 레코드 정화가 아니라 민감 값의 전체 수명주기(life cycle)를 관리하는 방식으로 접근해야 한다는 것이 이 연구의 출발점이다.

핵심 내용

  • SP-Mem(Sanitized Privacy-Mapped Memory) 제안: 메모리 유용성과 실제 민감 값 노출을 분리(decouple)하는 프라이버시 인지 메모리 아키텍처.
  • 전 수명주기 설계: 원시 입력에서 민감 정보를 식별·분리하고, 정화된(sanitized) 콘텐츠와 실제 민감 값을 격리된 구조에 각각 저장.
  • 작업 요구사항과 사용자 동의에 기반해 민감 값을 선택적으로만 검색(retrieve)하는 메커니즘으로 불필요한 노출 최소화.
  • 응답 품질·프라이버시 행동·추론 비용을 함께 평가하는 프라이버시 인지 메모리 벤치마크를 도입하고, 다수 LLM 기반 에이전트 실험에서 SP-Mem이 더 강한 개인화를 유지하면서 불필요한 프라이버시 노출을 줄임을 입증.

보안 시사점

  • AI 에이전트가 장기 메모리에 PII를 축적·재사용하는 방식은 데이터 유출 사고 시 피해 범위를 확대하는 핵심 공격면이다. SP-Mem의 '정화 저장 + 격리 + 선택적 검색' 구조는 침해 발생 시 노출되는 민감 데이터의 표면을 줄이는 방어 설계 원칙을 보여준다.
  • 메모리 프롬프트 인젝션·탈취 공격에 대비해, 민감 값을 별도 격리 구조에 두고 작업 필요 시에만 노출하는 것은 최소 권한(least privilege) 원칙을 메모리 계층에 적용한 사례로 볼 수 있다.
  • 사용자 동의 기반의 선택적 검색은 GDPR 등 개인정보 규제에서 요구하는 데이터 최소화·목적 제한 원칙을 에이전트 메모리 설계에 실용적으로 구현하는 방향을 제시한다.
  • 개인화 유용성과 프라이버시를 함께 평가하는 벤치마크가 공개되어, 향후 에이전트 메모리 보안 연구의 비교·검증 기준으로 활용될 수 있다.

결론

이 연구는 대화형 에이전트의 장기 메모리에서 개인화 유용성을 희생하지 않으면서 PII 노출을 최소화하는 SP-Mem 아키텍처를 제시한다. 민감 정보의 식별·분리, 정화 저장, 동의 기반 선택적 검색이라는 전 수명주기 설계를 통해 기존 메모리 시스템의 '저장하면 노출된다'는 구조적 취약점을 완화했으며, 다수 LLM 에이전트 실험에서 개인화 성능을 유지하면서 불필요한 프라이버시 노출을 줄이는 효과를 검증했다. AI 에이전트 메모리 보안의 기준이 될 수 있는 의미 있는 연구다.
