베를린 주정부가 8월 발생한 주 행정망 침해와 관련한 갈취 시도에 직면했다고 공식 확인하면서도, 협박 요구에는 응하지 않겠다고 밝혔다. 같은 발표에서 감정 작업 중 모빌리티·교통·기후보호·환경 담당 상원 부서(Senate Department) 소관에서 8월 7일~12일 사이 추가 데이터 유출도 발견됐다고 공개했다.

  • 공격 주장: 유출 사이트에 8월 28일 게시된 게시물이 5.79TB 데이터와 12,076명의 개인정보를 보유하고 있다고 주장 — 베를린 측은 유출 규모 수치를 공개하지 않아 공격자 측 주장이 유일한 계상
  • 대응 방침: "베를린 주정부는 협박당하고 있다" — 카이 베그너(Kai Wegner) 시장은 특별 상원 회의 후 범죄자와 협상하지 않겠다는 입장 표명. 피해자 대상 안내도 8월 29일 현재 미공개 상태
  • 사고 타임라인: 8월 7일 첫 유출 보고 → 8월 14일 네트워크 차단 → 8월 28일 유출 사이트 게시. 개인정보·비공개 데이터 포함 가능성 배제할 수 없다고 발표
  • 시사점: 공공기관이 몸값 요구를 공개적으로 거부한 사례로, 랜섬웨어 협상 전략과 데이터 유출 대응 커뮤니케이션의 기준점이 될 전망

2. Cosmos EVM 모듈 치명적 결함, 6개 블록체인에서 자금 탈취 — 수정 11일 전 '안전' 판정 논란

Cosmos Labs가 공유 Cosmos EVM 모듈의 치명적 잔액 처리 결함(GHSA-7g4w-cg88-2cq2)이 2026년 8월 20일~25일 사이 6개 블록체인의 자금을 탈취하는 데 악용됐다고 경고했다. 취약점은 CVE 식별자·약점 분류·CVSS 점수 없이 'Critical'로 공시됐다.

  • 영향 범위: < 0.6.2 및 >= 0.7.0 < 0.7.2 버전 — 수정은 8월 19일 v0.6.2와 v0.7.2로 배포됐으나, 상태 변경(state-breaking) 업그레이드라 체인 운영자의 조율된 네트워크 업그레이드가 필요. 즉시 업그레이드가 불가능하면 거버넌스 업그레이드 대신 체인 중단(halt) 권고
  • 판정 오류: 버그바운티로 4월 25일 신고됐으나 당시 "라이브 네트워크 자금 위험 없음"으로 평가 — 18자리 소수점 네트워크에서 재현 실패로 "18자리 미만 네트워크만 영향"이라는 잘못된 결론. 8월 13일에야 모든 Cosmos EVM 체인이 소수점 설정과 무관하게 영향받음을 확인
  • 사후 분석: 8월 28일 포스트모템 공개 — 신고부터 악용까지 4개월의 공백과 재현 실패가 실제 탈취로 이어진 과정을 투명하게 공개
  • 시사점: 공유 모듈 기반 블록체인 생태계에서 단일 결함의 파급력과, 버그바운티 '재현 실패' 판정의 위험성을 보여준 사례

3. PaperCut, 두 결함 체이닝 무인증 RCE — 1차 패치 우회 발견으로 2차 긴급 패치 배포 [후속]

프린트 관리 소프트웨어 PaperCut NG/MF를 노린 공격자들이 신규 패치된 결함을 체이닝해 무인증 원격 코드 실행(RCE)을 달성하고 있다. PaperCut은 연구자들이 1차 패치의 우회 경로를 다수 발견함에 따라 추가 하드닝을 포함한 2차 긴급 패치(Emergency Patch Release 2)를 배포했다. (8/28 게시물의 제로데이 긴급 패치 후속)

  • CVE-2026-81578 (인증 우회, High): 접근 검증 완료 전에 백엔드 액션을 수행할 수 있는 결함 — 공격자가 무인증 요청으로 서버 설정을 변경하고 민감 엔드포인트에 접근해 임의 Java 코드 실행 가능 (Huntress: John Hammond·Andrew Brandt)
  • CVE-2026-82078 (동적 클래스 로딩, CVSS 9.4 Critical): DB 연결 유틸리티가 허용 목록(allowlist) 검증 없이 설정 가능한 드라이버 이름으로 DB 드라이버 클래스를 로드 — 공격자가 설정을 조작하면 클래스패스의 임의 Java 바이트코드를 PaperCut 서버 프로세스 권한으로 실행
  • 2차 긴급 패치: 내부 보안팀 + Huntress + watchTowr 공동 분석으로 1차 패치 우회를 차단하는 하드닝 포함 — NG/MF 25·26 버전 대상
  • 전례: 2023년 CVE-2023-27350 무인증 RCE는 Clop·LockBit 랜섬웨어, 이란 정부 지원 그룹, Bl00dy 랜섬웨어 갱단이 초기 침투 경로로 악용 — 이번 사태는 그 전철을 밟는 중

  • 공격 정황 (Hunt.io): 호스트 31.58.209[.]241의 공개 디렉터리에 커스텀 파이썬 스크립트와 Sliver·Metasploit·Mettle 등 오픈소스 공격 도구를 스테이징 — 필리핀 조직 2곳(원자력 연구기관 + 필리핀 해군에 서비스하는 해양공학·조선업체)에서 데이터 탈취

VulnCheck가 중국 심천 Zhibotong Electronics(ZBT)가 제조한 라우터 펌웨어에서 미문서화 공장 임플란트 2종을 발견했다. 각각 무인증 원격 공격자에게 루트 명령 실행 능력을 제공하며, CVE-2026-74232와 CVE-2026-74233으로 추적된다.

  • SPEAKINGSTONE (CVE-2026-74232): 'yunmgrd' 서비스로 실행, UDP 10000 포트로 하드코딩된 C2 서버에 비콘 전송 — NAT·일반 egress 필터링 뒤에서도 동작하는 외발(outbound) 통신. 루트 명령 실행, WAN PPPoE 사용자명·비밀번호 탈취, DNS 하이재킹 목록 읽기·쓰기, 역방향 SSH 터널 개설 지원 — "실행되는 모든 장치에 대한 루트 권한을 가진 감시 임플란트"
  • DARKLANTERN (CVE-2026-74233): 'infosrvd' 서비스로 UDP 9992 포트에서 동작하는 두 번째 임플란트
  • 심각도: 두 CVE 모두 VulnCheck가 CNA로 배정 — CVSS 4.0 기준 9.3, CVSS 3.1 기준 9.8. 네트워크 공격, 권한·사용자 상호작용 불필요
