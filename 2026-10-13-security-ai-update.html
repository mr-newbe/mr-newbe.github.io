1. [사건] 프랑스 대형마트 냉장·냉동 설비 원격 조작 — 냉동고가 ‘오븐’이 됐다, 250~350개 매장

10월 11일 밤부터 12일 새벽 사이, 공격자들이 프랑스 대형 유통 체인의 댄포스(Danfoss) 냉동 제어기를 원격으로 장악해 냉장·냉동고의 자동 제상(defrost) 기능을 역이용, 온도를 냉각이 아니라 가열 방향으로 밀어 올렸다. Intermarché·Netto·Coopérative U(Super U)·Leclerc·Carrefour Market·Monoprix 등 250~350개 매장이 영향을 받았고, 일부 매장에서는 실제 화재까지 발생했다. 파리 검찰은 “식품 손실 및 화재 발생과의 연관성을 확인하기 위한” 수사에 착수했다.

  • 공격 방식: 구버전 댄포스 제어 소프트웨어를 실행하던 냉동 컨트롤러를 탈취해 내장 제상 스케줄을 조작. Claroty Team82는 2025년 5월 인증 우회(CVE-2025-41450)와 2025년 8월 명령 주입(CVE-2025-41451)을 AK-SM 8xxA 시리즈에서 발견해 공개했고, 벤더는 펌웨어로 수정했지만 구버전 장비가 현장에 그대로 남아 있었다. 이번 공격이 이 결함을 악용했는지는 아직 공식 확인되지 않았다.
  • 피해 규모: 매장당 수십만 유로 수준의 손실 추정 — 콜드체인 붕괴로 신선·냉동 식품 전량 폐기, 매대 폐쇄, 일부 점포 화재. 프랑스 정부는 “국민 식량 공급에 필수적인 설비를 겨눈 전례 없는 중대 사안”이라고 규정했다.
  • 노출 면: Predicta Lab의 Baptiste Robert는 10월 12일 기준 인터넷에 노출된 댄포스 시스템 2,752대(프랑스 1,590대)를 확인했고, Shodan은 인터넷 도달 가능 댄포스 장비를 4,500대 이상 추적 중이다. 냉장제어 벤더·설치업체(Axima)·댄포스가 참여하는 위기 대응 회의가 소집됐다.
  • 별건 — Ahold Delhaize: 같은 날 네덜란드 유통 대기업 아홀트 델하이즈도 “네트워크 보안 이슈”로 일부 시스템을 오프라인 전환했다. 네덜란드 Albert Heijn·Etos·Gall & Gall과 벨기에 Delhaize의 웹·앱·고객센터가 마비됐고, 미국 Stop & Shop 직원은 근무표·급여명세에 접근하지 못했으며 Food Lion은 내부 메모에서 “주문 픽업·인계가 불가할 수 있다”고 공지했다. 2024년 11월 INC Ransom으로 220만 명 정보가 유출된 이후 2년 새 두 번째 대형 사고다.
  • 시사점: 랜섬웨어 없이도 물리적 결과(부패·화재·영업 중단)를 만들어내는 OT 공격이 소매·콜드체인에서 현실화됐다. 인터넷에 직접 노출된 냉장/HVAC 컨트롤러는 ‘패치 대상 목록’이 아니라 ‘자산 목록’에서 먼저 찾아야 한다.

2. [사건] Ledger 지갑에 하드웨어 임플란트 — 화면 뒤 회로가 시드 24단어를 LTE로 전송, 피해 추정 $93M

하드웨어 지갑 제조사 Ledger가 동남아 리셀러 CryptoBilis(말레이시아)를 통해 판매된 기기에서 비인가 하드웨어 임플란트를 확인했다. 9월 16일부터 연구자들이 개조된 Ledger X를 포착했고, 10월 9일 사용자 자금 유출 신고가 몰리자 Ledger가 조사에 착수해 10월 10일 최소 1대에서 임플란트를 확인했다. 온체인 분석가들은 피해 규모를 9,300만 달러 이상으로 추정한다.

  • 임플란트 구조: 전 Mt.Gox CEO 마크 카르펠레스(現 Karpelès Lab)가 화면 아래 패딩 자리에 숨겨진 소형 회로를 공개했다 — ST STM32G431KBU6(Arm Cortex-M4, 128KB 플래시), 안테나, LTE 칩, 초소형 eSIM. 원래 배터리를 더 작은 것으로 교체해 악성 회로 공간을 확보했다.
  • 작동 원리: “임플란트는 화면에 표시되는 내용을 감시하고, 시드 구문이 표시되는 순간 기록해 외부로 전송한다.” 시드만 확보하면 공격자는 원본 기기를 건드리지 않고 언제든 지갑을 복원해 자금을 비울 수 있다 — 시드를 조용히 모아 한꺼번에 털어가는 방식이라 10월 9일의 유출 물결과 정황이 맞는다.
  • 은폐 수준: 정품 수축 포장 상태로 도착했고 Ledger Genuine Check도 통과했다(내부 보안칩은 진품). 추가 회로를 찾는 신뢰할 수 있는 방법은 기기를 열어보는 것뿐이다. Tibane Labs는 임플란트 두 가지 버전을 확보했다고 밝혔다(Amazon Japan 중국 셀러·말레이시아 발송, Yahoo! 옥션 재팬).
  • 대응: Ledger는 CryptoBilis 취급을 중단하고 “최근 90일 내 구매자는 기기를 초기화하지 말 것, 이미 설정했다면 새 시드로 새 기기로 자산을 옮길 것”을 권고했다. CryptoBilis는 하드웨어 지갑 재고 판매를 전면 중단했다. Bitquery는 추적한 유출 지갑 8할 이상이 6월 이후 최초 입금이라며 90일 기준이 충분하지 않을 수 있다고 지적했다.
  • 시사점: ‘공인 리셀러 구매’도 보증이 아니라는 것이 증명됐다. 하드웨어 신뢰는 리셀러·유통 단계의 물리적 무결성 검증(개봉 검사, 시리얼-시드 대조) 없이는 성립하지 않는다.

3. [사건] CyberXero — Claude Code 에이전트 51개 + PentAGI·Cobalt Strike로 우크라이나 62.8만 건 탈취

SOCRadar가 러시아어권 금전 목적 초기침투 브로커 ‘CyberXero’(최소 2026년 7월부터 활동)를 공개했다. 이 조직은 전 세계 자동 대량 캠페인(WordPress·이커머스)과 우크라이나 에너지·필수 인프라 대상 수작업 캠페인 두 갈래를 동시에 운영하며, 확인된 유출은 우크라이나 개인 정보 62만 8천 건 이상이다.

  • AI 사용 형태 2단계: ① 공격자 워크스테이션에서 Claude Code + 특화 에이전트 51개 클러스터를 스캔·익스플로잇 체인·정찰·후속 침투에 사용 ② 오픈소스 자율 펜테스트 에이전트 PentAGI를 Cobalt Strike 팀 서버에 AI 프로바이더 API로 연결해 페이로드 생성·실행.
  • 속도: 단일 자동 실행이 4,708개 대상을 스캔해 429개 WordPress 관리자 패널 접근에 성공했고, 61초 안에 웹셸 32개를 배포했다. 악용한 결함은 wp2shell(CVE-2026-63030·CVE-2026-60137)과 Support Board 플러그인 SQL 인젝션(CVE-2026-4815) 등 이미 알려진 취약점이다.
  • 가해지는 곳: 우크라이나 4개 기관 확정 유출(하르키우 난방 공급사 포함), 폴란드·중국·네덜란드에서도 침해 확인. 공격 인프라는 워크스테이션·프로비저닝 서버·수익화 인프라·페이로드 스테이징·스캐너 등 8개 노드.
  • 안전장치 우회와 한계: 모델 거부를 피하려 세션 리셋 + “내 인프라에 대한 승인된 펜테스트” 컨텍스트 주입을 반복했다(“안전 통제는 가중치가 아니라 세션 컨텍스트에 작동하므로 한 세션의 거부가 다음 세션으로 이어지지 않는다”). 다만 로그에는 실제로 버틴 거부도 남아 있다 — 백도어 설치·방화벽 비활성화·측면 이동·웹셸 배포를 4회 반복에서 거부했고, 위조된 소유권 토큰도 거부했다.
  • 왜 이게 최초 유출로그인가: 노출된 오픈 디렉터리(46.21.250[.]135)에 AI 세션 로그, 평문 토큰이 든 스크립트, 익스플로잇 툴킷, 정찰 결과, 에이전트 설정, 유출 데이터가 그대로 있었다. 캠페인은 현재 진행 중이다.

4. [취약점] GitLab CI/CD 정규식 컴파일러 CVE-2026-97229 (CVSS 10.0) — 무인증 원격 코드 실행

GitLab이 최대 심각도 결함을 긴급 패치했다. CI/CD 정규식 컴파일러의 정수 오버플로로, 무인증 사용자가 CI/CD 설정 파일에 특수 제작된 정규식을 넣어 GitLab 서버에서 임의 코드를 실행할 수 있었다. GitLab.com은 이미 패치됐고 Dedicated 고객은 조치가 필요 없지만, 셀프호스팅 인스턴스는 즉시 업그레이드해야 한다.

  • 영향 버전/수정 버전: CE·EE 19.2 < 19.2.8, 19.3 < 19.3.4, 19.4 < 19.4.2. 신고자는 HackerOne 버그바운티 경유 ‘joaxcar’.
  • 왜 심각한가: GitLab은 등록 사용자 3,000만 명, Fortune 100의 절반 이상이 쓰는 DevSecOps 플랫폼이다. 지난달에도 무인증 데이터 읽기 결함(CVE-2026-85706)이 공개 하루 만에 CISA KEV에 등재됐다 — CI/CD 플랫폼 결함은 곧바로 공급망 문제로 번진다.
  • CISA가 2021년 11월 이후 악용된 GitLab 결함 5건을 플래그했고, 그중 하나는 랜섬웨어 조직이 사용했다.
  • 동시 경고 — Citrix NetScaler: CISA가 신규 공개된 NetScaler 결함에 대해 고객 패치를 촉구했다(Cybersecurity Dive, 10/12). 앞서 10월 9일 경고된 NetScaler RCE(CVE-2026-107406, SAML 구성 인스턴스 대상)에 이어 같은 제품에서 연속 경고가 나오는 흐름이다. ※ 신규 결함의 세부 CVE 목록은 원문 접근 제한으로 이번 확인에서 확정하지 못했다.

5. [취약점] WordPress 생태계 — CVE-2026-85097 실제 익스플로잇 + 테마·플러그인 CVSS 9.8 대량 결함

Patchstack은 Bricksforge 플러그인의 CVSS 10.0 무인증 RCE가 실제 공격에 사용되고 있다고 밝혔다. 동시에 이번 주 NVD에는 WordPress 테마·플러그인에서 9.8 등급 결함이 무더기로 올라왔다 — 원인은 대부분 같다: 클라이언트가 보낸 메타데이터를 서버가 다시 검증하지 않는다.

  • Bricksforge CVE-2026-85097 (10.0): 3.1.8.9 이하 영향, 3.1.8.10에서 수정. ① 무인증 AJAX 엔드포인트(bricksforge_regenerate_nonce)로 유효한 nonce 획득 → ② GIF/PHP 폴리글랏 파일 업로드(MIME 검사는 통과) → ③ 폼 제출 시 temporaryFileUploads의 file 경로는 검증된 GIF, url 필드만 .php로 위조 → ④ 서버가 메타데이터를 그대로 믿고 PHP 위치에 배치 → 실행.
  • 실제 공격 정황: Patchstack은 10월 7일 21:47 UTC 첫 시도를 탐지했다. 텔레메트리에서 44개 IP가 수 초 안에 동일 페이로드 56건을 쏘았고, 별도 클러스터는 3개 IP가 25개 변형을 시험했다. 확장자 필터는 .php5·.php7·.phtml·대소문자(.PHP)·인코딩(%70hp)으로 우회한다. 공격 표적은 /wp-json/bricksforge/v1/form_submit와 admin-ajax.php.
  • 테마 대량 결함: ThemeREX·Axiomthemes 계열 테마 약 20종에서 Object Injection(역직렬화) 9.8이 동시 공개됐다(Booklovers·Veto·Gutentype·Travesia·Tantra·Smash·Smart Casa·Rosalinda·Partiso·Let’s Play·IPharm·Hygia·Hogwords·Greeny·Edema·Dwell·Convex·Camelia·Balance 등) — 한 벤더의 코드 재사용이 곧 한 번에 20개 제품이 취약해지는 구조를 보여준다.
  • 같은 주의 9.8 플러그인: Advanced IP Blocker 8.13.13 이하 인증 우회(handle_login_action() 서버측 검사 부재) · Extensions for CF7 3.4.5 이하 임의 파일 업로드(extcf7_submit) · 3D Product Configurator for WooCommerce 2.16.2 이하 RCE(xpv_image) · WPCOM Member 1.7.27 이하 소셜로그인 콜백 인증 우회(uuid·code) · rtMedia 경로 탈출(9.8) · openapi-typescript-codegen 0.31.0 이하 코드 주입(OpenAPI 문서로 JS 주입, 9.8) · Blocksy Companion 2.1.58 이하 권한 상승(9.1).
  • 대응: 테마·플러그인 목록을 ‘설치됨’ 기준으로 전수 조사하고 자동 업데이트를 켠다. 미사용 테마·플러그인은 삭제한다. 웹셸 흔적(wp-content/uploads/bricksforge/tmp 하위 실행 가능 파일)을 확인한다.

6. [취약점] 경계 어플라이언스·임베디드 — SonicWall SMA1000 익스플로잇 135건, 라우터·모뎀 무인증 9.8~10.0

SonicWall SMA1000의 사전 인증 SSRF CVE-2026-102255(CVSS 10.0)가 패치 이틀 만에 실제 공격을 받았다. 같은 주 NVD에는 라우터·모뎀·통신 장비에서 무인증 원격 코드 실행 결함이 연달아 올라왔다.

8. [트렌드] BYOA — 직원의 개인 AI 에이전트는 이미 회사 시스템에 로그인되어 있다

‘직원이 데려오는 개인 AI 에이전트(Bring Your Own Agent)’가 새 공격면으로 정리됐다. 오픈소스 에이전트 OpenClaw 이후 1년도 안 돼 개인 비서형 에이전트가 쏟아졌고(Amazon은 봇 식별 표기가 없다는 이유로 Meta Muse를 차단, Instinct는 프라이버시 논란), 직원들이 개인 에이전트를 업무 시스템에 연결하는 일은 막을 수 없다는 전제가 핵심이다.

  • 들어오는 5가지 경로: ① OAuth 동의(테넌트가 사용자 동의를 허용하면 ‘허용’ 클릭 한 번으로 끝) ② 문자 스레드형(Instinct — 사용자가 문자로 지시하고 Google·Apple·Facebook 계정을 연결) ③ 에이전트 브라우저에 저장된 비밀번호(앱 입장에서는 ‘직원이 로그인한 것’으로 보인다) ④ 비공식 연동용 API 키·개인 액세스 토큰(장기 자격증명) ⑤ 직원 노트북의 로컬 에이전트(OpenClaw—그 기기가 볼 수 있는 모든 것에 접근, Muse의 Mac 앱은 파일·메모·캘린더·메일 열람에 선택적 Full Disk Access까지).
  • BYOD와의 결정적 차이: 기기 등록(BYOD)은 IT가 ‘등록할 대상’을 줬지만, 개인 에이전트는 등록할 수 있는 물건이 아니다. 벤더 서버에 살거나 직원 기기 사이에 섞여 들어간다.
  • 대응 방향: 차단이 아니라 ‘정체성을 통제 평면(control plane)으로’ 두는 것 — 소유자 기록이 있는 신원, 제한된 승인 범위, 오프보딩 절차를 갖춘 에이전트만 허용하고, 직원을 사칭하는 에이전트와 소유자 불명 에이전트를 식별해 분리한다.
  • 같은 흐름의 도구: AWS가 공개한 오픈소스 에이전트 샌드박스 Strands Box, 마이크로소프트의 에이전트 의사결정 모델 DECISION-1 — 에이전트를 ‘격리’와 ‘판단’ 양쪽에서 다루는 인프라가 표준화되고 있다.

9. [트렌드] AI가 패치를 쓴다 — ‘크래시가 멈추면 성공’이라는 채점이 실패를 성공으로 만든다

노스웨스턴대 연구진이 실제 보안 버그 112개(C/C++·Go·Rust, 84개 오픈소스 프로젝트)로 AI 코딩 에이전트를 평가한 결과가 나왔다. 결론은 불편하다: 크래시를 막는 패치가 유지보수자가 그 수정과 함께 작성한 테스트는 통과하지 못하는 경우가 많다.

  • 평가 자체의 함정: 검토한 벤치마크 13개 중 AI 에이전트용 5개 모두 9개 함정 중 최소 1개를 처리하지 않았다. ‘코드를 어떻게 빌드·테스트하라’고 알려주는 것만으로 C/C++ 버그 성공률이 20%포인트 올랐다(모델이 똑똑해진 게 아니다).
