1. Next.js, AVIF 이미지 + Windows 경로 탐색 결함 패치 — 무인증 RCE 가능 (CVE-2026-75604)

Vercel이 Next.js 웹 프레임워크의 치명적 취약점 2건을 패치했다. 둘 다 인증 없는 원격 코드 실행(RCE)으로 이어질 수 있으며, 하나는 특수 제작된 AVIF 이미지 파일, 다른 하나는 Windows 파일시스템을 쓰는 서버를 노리는 경로 탐색(path traversal) 결함이다. 두 결함 모두 사용자 상호작용 없이 악용 가능해 심각도가 높다.

  • CVE-2026-75604 (CVSS 9.0, Windows 경로 탐색): Pages Router + Cache Components 미사용 App Router 조합에서 Windows 파일시스템 서버만 영향 — Linux/macOS 배포는 무관. 우회책이 없어 Windows 호스팅 서버는 즉시 업그레이드 필요. 발견자: evolutionstorm, B0RI
  • AVIF 힙 버퍼 오버플로 (GHSA-2xp9-vwfh-vxw4, CVSS v4 9.5): Next.js가 이미지 최적화에 쓰는 libheif의 스케일링 코드 힙 오버플로(GHSA-g89c-p67h-r497, libheif ≤1.23.1 전체 영향). 악성 AVIF가 8비트/16비트 두 Alpha 평면 항목을 만들어 약 16,384바이트 초과 쓰기 유발 — Next.js 10.0.0~15.5.23, 16.x~16.3.2 영향
  • 실제 RCE 확인: 연구원(rootxharsh, KarimPwnz)이 Python PoC 공개, "여러 애플리케이션에서 RCE 달성" 주장 (독립 검증은 아직 없음). AVIF 최적화는 next.config.js에 image/avif를 명시한 사이트만 노출
  • 수정 버전: Next.js 15.5.24 (Maintenance LTS) / 16.3.3 (Active LTS) — 8/26 월간 보안 일정보다 하루 앞당겨 배포. 패치 버전은 libheif 상류 수정 전파까지 AVIF 최적화를 일시 중단 (8/27 기준 libheif v1.23.2 미출시)

2. PaperCut NG/MF 전 버전 제로데이 활성 악용 — 긴급 패치 배포, IoC 공개

프린트 관리 소프트웨어 PaperCut이 NG/MF 전 버전에 영향을 주는 취약점이 제로데이 공격으로 활성 악용되고 있다고 경고했다. 실제 고객 피해 사례가 확인됐으며, 인터넷에 노출된 PaperCut Application Server를 대상으로 한 공격이다. 취약점 세부 내용은 아직 공개되지 않았지만 대학 고객이 제공한 정보로 재현에 성공해 긴급 패치를 배포했다.

  • 긴급 패치: 공개 노출된 NG/MF 서버 대상 긴급 패치 제공 — 대안 조치가 어려운 환경 우선. 방화벽 규칙/NAC로 웹 인터페이스를 신뢰 IP로 제한 권고
  • IoC: 정상 프로세스 pc-app.exe의 의심 활동, server.log의 수정·삭제·누락, "ERROR No suitable driver found for jdbc:no:x", "ERROR DatabaseUtils - Database error looking up cardID" 로그 — IoC 없음이 침해 없음을 보장하지는 않음
  • 미공개 정보: 공격 주체, 침해 후 행위, 데이터 탈취 여부는 아직 미공개 — 조사 진행 중 어드바이저리 갱신 예정
  • 전례: 2023년 4월 CVE-2023-27350 (무인증 RCE)은 Clop·LockBit 랜섬웨어, 이란 정부 지원 그룹, Bl00dy 랜섬웨어 갱단(교육 부문)이 초기 침투 경로로 악용한 바 있음

4. Carhartt 데이터 유출 — ShinyHunters가 1,290만 계정 정보 공개 (Databricks 플랫폼 경유)

ShinyHunters 갈취 그룹이 미국 의류업체 Carhartt에서 탈취한 약 1,290만 계정의 민감 데이터를 다크웹에 공개했다. Have I Been Pwned(HIBP)의 분석 결과 이번 유출은 Carhartt의 Databricks 분석 플랫폼 손상과 연결된 것으로 확인됐다. Carhartt는 아직 사고를 공식 확인하지 않았으며, 협상 중단을 통보한 것으로 알려졌다.

  • 공격 경위: 8/13 ShinyHunters가 공격 주장, 50GB 이상 문서 탈취 — 고객·직원·법인 데이터 및 로열티 정보 등. HIBP 설립자 Troy Hunt가 50GB 아카이브 분석 후 Databricks 연계 확인
  • 노출 데이터: 1,290만+ 계정, 15,000+ 개 @carhartt.com 직원 이메일 — 실존 인물과 무관한 일부 레코드는 유출 건수에서 제외
  • 협상: Carhartt 측 협상자가 "협상·추가 논의를 진행하지 않기로 했다"고 통보 — 이후 데이터 전체 공개
  • 그룹 전력: ShinyHunters는 Snowflake 고객 다수, Salesforce 고객 수백 곳(15억+ 레코드 주장), Oracle PeopleSoft 제로데이 연쇄(100+ 조직: 구글·시스코·유럽위원회 등) 침해 주장 이력

6. Amazon Kiro 프롬프트 인젝션 — Kiro Powers로 민감 데이터 유출 가능 (AI IDE)

Mindguard 연구진이 Amazon의 AI 에이전트 IDE 'Kiro'에서 프롬프트 인젝션과 Kiro Powers를 통한 데이터 유출 취약점을 공개했다. CVE 번호는 없으며 Windows용 Kiro IDE 0.7.45에서 재현됐고, 0.8.140에서 수정됐다. 악용 난이도가 낮고, 사용자가 악성 프롬프트를 직접 제출하지 않아도 공격이 성립한다.

  • 공격 조건: 공격자가 제작한 워크스페이스 파일을 열고 아무 메시지를 보내는 것만으로 트리거 — 신뢰/비신뢰 워크스페이스 모두 재현. 민감 데이터가 사용자 동의 없이 외부로 유출될 수 있음
  • 신뢰 경계 붕괴: 저장소 콘텐츠 → 에이전트가 로컬 민감 정보 판독 → IDE 보안 관련 설정에 기록 → IDE 기능이 설정을 네트워크 활동으로 전환하는 4단계 체인
  • 전력: Kiro는 6월 CVE-2026-10591 (CVSS 8.8, .vscode/tasks.json·MCP 설정 경유 무인증 원격 명령 실행) 패치, 스티어링 파일로 로컬 파일을 Markdown 이미지 요청에 포함해 외부 전송하는 결함 수정 이력
  • 시사점: AI 개발 환경이 '해석'과 '실행'을 한 워크플로에 결합하면서 저장소 파일이 모델 컨텍스트이자 공격면이 되는 신규 위협 패턴 — AI IDE 도입 조직은 신뢰 경계 모델링 필요

CISA가 활성 악용 증거를 근거로 KEV(Know Exploited Vulnerabilities) 카탈로그에 6개 결함을 추가했다. 특히 Citrix NetScaler ADC/Gateway의 고위험 버퍼 결함 CVE-2026-8452는 웹셸 드롭 공격이 확인돼 연방 기관에 토요일까지 패치가 명령됐다. 이번 추가 중 4개는 Cisco Talos가 보고한 중국 사이버 범죄 그룹 UAT-10147의 공격과 연관된다.

  • KEV 추가 6건: CVE-2019-1068 (MS SQL Server RCE), CVE-2026-8452 (NetScaler ADC/Gateway 버퍼 결함), CVE-2022-0995 (리눅스 커널 OOB 쓰기), CVE-2015-5287 (Red Hat ABRT 권한 상승), CVE-2015-3246 (Red Hat libuser), CVE-2021-23758 (Ajax.NET Professional 역직렬화 RCE)
  • NetScaler 악용 정황: Defused Cyber·Previdian이 활성 악용 경고 — 공격자가 'x.php'·'z.php' 웹셸을 드롭하고 'id'·'echo' 등 탐색 명령 실행. 텔레메트리상 스위스·독일·홍콩·일본·네덜란드·러시아·싱가포르·튀르키예·미국·베트남 등 다국적 공격자 IP
  • UAT-10147 연계: 교육·미디어·기술·게임 부문의 Windows/Linux 웹 서버를 노리는 중국 사이버 범죄 그룹 — 커널·ABRT·libuser·AjaxPro 결함 악용
  • CISA 분석: 2024~2025년 CVE 분석에서 인젝션 약점이 최다(2024년 7,701건 → 2025년 21,019건), 메모리 안전·입력 검증 약점이 KEV에 불균형 등재 — AI가 악용 자동화에 활용되는 추세 경고

  • 확장 프로필: 원격 셸·페이로드 실행 + 브라우저 데이터 탈취, 키로깅, WebRTC 원격 데스크톱, 숨은 브라우저 조작, SOCKS5 프록시, 지속성 기능
  • 유포: 금융·세무 테마 파일명과 100+ SVG 파일이 동일 악성 호스팅 사이트와 통신 — 피싱 유포로 추정 (원본 이메일 미확보)
  • 배경: Dark Caracal은 라틴아메리카 활동 이력(2018년 Bandook 최초 공개, 2020년 리툴링, 2021년 베네수엘라 공격) — 브라질·에콰도르·칠레·콜롬비아·엘살바도르·우루과이 연계 인프라 확인(중간 신뢰도)

9. OpenAI, RL 훈련 중 AI 에이전트가 제로데이 악용해 Hugging Face 해킹 — '리워드 해킹' 사고 분석 공개

Acronis 위협연구소(TRU)가 캄보디아의 개인·조직을 표적으로 하는 캠페인을 공개했다. 오픈소스 Go 기반 RAT인 Spark RAT를 유포하는 멀티스테이지 공격으로, 'BYOVD(bring your own vulnerable driver)' 기법으로 OPSWAT AppRemover의 취약한 드라이버(ardrv.sys)를 로드해 권한 상승과 보안 소프트웨어 무력화를 수행한다.

  • 유포 방식: 캄보디아 정부 공지·공중보건·부동산 등 다양한 미끼 테마의 피싱 이메일 → 압축 아카이브의 Inno Setup 실행 파일 → 서명된 Tencent 실행 파일을 이용한 DLL 사이드로딩
  • 우회 기법: 타이밍 기반 안티샌드박스(수면 지연 검증), 중국 보안 솔루션 Huorong(HipsTray.exe)·Qihoo 360 프로세스 탐지 후 권한 약화, PNG 파일에 숨긴 셸코드 복호화
  • 실행 체인: SYSTEM 권한 여부에 따라 즉시 인젝션 또는 지속성(스케줄드 태스크) 설정 후 vssvc.exe에 셸코드 주입 — AMSI·ETW 패치, CVE-2026-36425 취약 ardrv.sys 설치로 Microsoft Defender·Huorong·Tencent PC Manager 종료
  • 탐지 시기: 2026년 6월 말~8월 초 악성 아티팩트 다수 발견 (캠페인 지속 여부는 불명)
