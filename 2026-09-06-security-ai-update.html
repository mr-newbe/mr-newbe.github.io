1. Magento·Adobe Commerce 신규 0-day 'StyleSmuggler', 무인증으로 스토어 서버 장악 — Adobe, 아직 패치·CVE 미공개

네덜란드 이커머스 보안업체 Sansec이 9월 5일, 로그인 없이 온라인 스토어 서버에서 악성코드를 실행할 수 있는 Magento Open Source·Adobe Commerce의 신규 미패치 취약점을 경고했다. Sansec이 발견해 StyleSmuggler로 명명한 이 결함의 공격은 9월 4일 시작됐으며, 성공 시 공격자는 스토어 서버에서 코드를 실행하고 지속형 백도어를 설치한다. Sansec은 "스토어가 지금 침해되고 있기 때문에 조기 공개한다"고 밝혔다.

  • 취약점: 무인증 코드 실행 체인 — 2.4.9를 포함한 모든 현재 버전 영향, Sansec이 2.4.7·2.4.8·2.4.9 클린 설치에서 전체 무인증 체인 재현 — 첫 피해자는 최신 패치 수준(2.4.6-p15, 7·8월 보안 업데이트 적용)으로 "패치 상태는 무관했다"
  • 제로데이 상태: 9월 6일 현재 Adobe는 권고·CVE·패치·워크어라운드 모두 미공개 — 보안 게시판에도 8월 11일 업데이트 이후 공지 없음, 차기 정기 보안 릴리스는 9월 8일 예정(이번 결함 포함 여부 불명)
  • 임시 완화: Sansec Shield 미사용 스토어는 Adobe 수정판 배포 전까지 GraphQL 임시 비활성화 권고 — 다만 헤드리스·PWA 스토어프론트는 GraphQL 필수라 적용 불가(호스팅사 Disrex 분석)
  • 독립 증거: Magento 호스팅·개발사 Disrex Group이 9월 5일 사고대응 저장소 공개 — 스토어 2곳 침해·1곳 공격 시도 확인, 두 스토어 모두 Sansec의 첫 관측 후 방어 수단이 존재하기 전 약 8시간의 공백기 안에 뚫림

2. JetBrains 자체 Cadence 환경, 미패치 TeamCity 경유로 침해 — AWS 자격증명·소스코드 유출 가능성, 전면 자격증명 회전 촉구

JetBrains가 지난달 자사 클라우드 GPU 컴퓨팅 서비스 Cadence 환경이 최근 공개된 TeamCity의 치명적 취약점을 악용한 공격자에게 침해당했다며, Cadence 사용자에게 실행에 쓰인 모든 자격증명·시크릿을 즉시 폐기·교체하라고 촉구했다. JetBrains는 패치 대응 과정에서 해당 서버의 패치가 누락됐던 점을 시인했다.

  • 취약점: CVE-2026-63077(CVSS 9.8) — TeamCity의 신뢰할 수 없는 데이터 역직렬화로 무인증 공격자가 인증 우회 후 TeamCity 서버 프로세스 권한으로 OS 명령 실행 — 실전 악용 확인, 8월 5일 CISA KEV 카탈로그 등재
  • 침해 일정: 침입은 8월 8일~24일 사이, JetBrains가 8월 23일 발견 — 경유 서버(api.cadence.jetbrains.com)는 이후 오프라인 전환, 공격자는 Cadence 서버의 2024년 백업에 접근
  • 노출 데이터: 사용자 이름·이메일·마지막 로그인 타임스탬프·IP, 2024년 서버 백업 전체(자격증명·구성·아티팩트·로그), JetBrains 직원 IAM 계정을 포함한 AWS IAM 사용자·시크릿 다수, AWS S3 버킷 파일 — PyCharm에서 동기화한 프로젝트 소스코드도 노출됐을 가능성
  • 대응: Cadence 실행에 사용된 모든 자격증명·시크릿 회전·폐기, PyCharm Cadence 플러그인의 액세스 토큰 전면 무효화 — "추가 영향 사용자는 없었다"고 밝혔으나 저장 데이터는 잠재 노출로 간주

3. VMware Workstation·Fusion 치명적 결함 패치 — VMXNET3 어댑터 정수 오버플로(CVE-2026-59346, CVSS 9.3)로 호스트 코드 실행

Broadcom이 VMware Workstation과 Fusion에 영향을 주는 보안 결함 2건을 수정하는 업데이트를 배포했다. 그중 치명적 결함인 CVE-2026-59346(CVSS 9.3)은 정수 오버플로로, VMXNET3 가상 네트워크 어댑터를 쓰는 VM에서 로컬 관리 권한을 가진 공격자가 호스트에서 코드를 실행할 수 있게 한다.

  • 취약점 1: CVE-2026-59346(CVSS 9.3) — 정수 오버플로, VMXNET3 가상 NIC 사용 VM의 로컬 관리 권한 공격자가 호스트에서 코드 실행 — @h4urek·@cameudis·Stan S가 발견 신고
  • 취약점 2: CVE-2026-59347(CVSS 8.1) — HGFS(호스트-게스트 파일 공유)의 스택 버퍼 오버플로, VM 내 로컬 관리 권한 공격자가 호스트에서 VMX 프로세스 권한으로 코드 실행 — Tencent Xuanwu Lab(Yeonghyeon Choi·Tianchen Chen) 신고
  • 영향·패치: Workstation·Fusion 25H2·26H1 버전 영향, 워크어라운드 없음 — VMware Workstation 26H1u1·Fusion 26H1u1에서 수정
  • 배경: 실전 악용 증거는 아직 없으나 VMware 제품은 공격 표적이 지속 — 지난달 vCenter의 CVE-2026-59309·CVE-2026-59310이 공개 5일 만에 악용되며 중국 연계 APT 의심 공격으로 47개국 361개 피해 IP가 침해되기도 함

4. PaperCut 신규 결함(CVE-2026-81578·CVE-2026-82078), 미국·유럽 교육기관 공격에 악용 — Arctic Wolf가 자격증명 탈취 캠페인 관측

Arctic Wolf Adversary Research Team이 새로 공개된 PaperCut 결함들이 미국과 유럽의 교육 부문(K-12 학교부터 주요 대학까지)을 노린 자격증명 탈취 공격에 악용되고 있다고 밝혔다. 공격자들은 인증 우회와 원격 코드 실행으로 이어지는 CVE-2026-81578·CVE-2026-82078 체인을 이용해 명령 실행과 정찰, 자격증명 수집을 수행했다.

  • 공격 활동: uname·whoami·ver·tasklist 등 탐지 명령 실행 및 "Administrator17" 권한 계정 생성 — 45.142.193[.]132에서 certutil.exe로 lsa_collect.exe·lsa_collect_small.exe·save_hives.exe 등 자격증명 탈취 도구 전달
  • 자격증명 탈취: lsa_collect.exe가 레지스트리 키를 추출해 시스템 BootKey 재구성 → SAM 데이터베이스 접근, findstr로 PaperCut *.config 파일에서 password·secret·ldap·token 키워드 검색 — 탈취한 로그인 정보로 환경 내 다른 중요 시스템 침투 우려
  • C2: 194.180.48[.]134에서 Meterpreter Java 페이로드를 받아 세션 수립, 손상 호스트의 /custom/pcp_*.txt 경로로 수확한 시스템·사용자 데이터 유출
  • 권고: PaperCut 서버의 인터넷 노출 차단, pc-app.exe를 부모 프로세스로 한 cmd.exe·powershell.exe 실행 및 whoami·tasklist·ver·uname -a 포함 명령 모니터링

5. Trezor, 물류 파트너 ShipMonk 침해로 미국 고객 67,000명 데이터 추가 노출 — "삭제했다"던 데이터가 남아있어

하드웨어 지갑 제조사 Trezor가 9월 4일(금), 물류 제공업체 ShipMonk의 침해로 미국 고객 67,000명의 데이터가 추가로 노출됐다고 공개했다. 이름·이메일·전화번호·배송 주소·주문번호(2019년 11월~2021년 8월)가 포함되며, 자사 90일 데이터 보존 정책상 이미 삭제·비식별화됐어야 할 구매 데이터가 남아 있던 것으로 나타났다.

  • 규모·시점: ShipMonk가 8월 10일 침해 통보 — 지난달 공개된 1,947명(이름·도시·이메일만 노출)과 별개로 이번에 67,000명 추가 확인
  • 근본 원인(공급망 공격): ShipMonk이 사용하던 Metabase의 SQL 인젝션 제로데이 CVE-2026-72898(CVSS 10.0) 악용 — 블록체인 보안업체 Holborn 분석 기준 갈취 조직 ShinyHunters 소행 추정, Metabase 인스턴스에 저장된 Trezor 고객 주문 정보가 노출됨
  • 하드웨어 지갑 안전: Trezor는 이번 침해가 하드웨어 지갑 보안에는 영향을 주지 않는다고 강조 — 그러나 유출 정보로 피싱 메일·가짜 전화·사칭 편지 등 사회공학 공격과 물리적 보안 위험 가능성 경고
  • 대응: 영향 고객 직접 통보, ShipMonk은 아직 공식적으로 사건을 인정하지 않았으나 시스템 보안 강화 조치 완료

7. 블록체인에 ClickFix 페이로드를 숨긴 대규모 작전 — 손상된 웹사이트 5,400개 이상, BSC 테스트넷 스마트 계약 활용(EtherHiding)

클라우드 보안업체 Netskope에 따르면 수천 개의 손상된 중소기업 웹사이트(대부분 WordPress·PrestaShop 기반)가 BNB 스마트체인(BSC) 테스트넷의 스마트 계약에 저장된 ClickFix 페이로드를 전달하는 대규모 사이버 범죄 작전에 이용되고 있다. 연구진은 지난 수개월간 5,400개 이상의 해킹된 사이트를 확인했으며, 블록체인에 악성 코드를 저장하는 'EtherHiding' 기법을 사용한다.

  • EtherHiding: BSC 테스트넷은 개발용으로 메인넷과 유사하게 동작하지만 무료 — 공격자가 스마트 계약에 악성 코드·설정을 저장해 차단이 어렵고 페이로드를 실시간으로 변경 가능한 복원력 높은 인프라 구축
  • 전달 체인: 주입된 스크립트가 가짜 CAPTCHA ClickFix 유인을 표시, 방문자에게 Windows 실행 대화상자(Win+R)를 열어 PowerShell 명령을 붙여넣게 유도 → 최종 페이로드 다운로드·실행
  • WebRTC 트릭: 스테이저가 정상 WebRTC 핸드셰이크처럼 offer를 생성한 뒤 응답을 스스로 '직접 작성'해 연결에 피드백 — 실제 핸드셰이크 없이도 공격자와 데이터 채널이 열리고, 수신 코드는 디스크에 저장하지 않고 브라우저 메모리에서 동적 실행
  • 규모·대응: 하루 300개 이상의 감염 사이트가 RPC 엔드포인트 접촉, 8월에는 거의 매일 400개(최고 536개) — BSC 테스트넷 RPC 엔드포인트 풀 차단 및 WebRTC 관련 비웹 UDP 트래픽 모니터링 권고

8. HPE, ArubaOS-CX 치명적 RCE 패치 — 무인증 원격 공격 가능한 버퍼 오버플로(CVE-2026-73749) 포함 24건 수정

HPE가 엔터프라이즈 네트워크 스위치 OS인 ArubaOS-CX의 치명적 취약점을 패치했다. CVE-2026-73749로 추적되는 버퍼 오버플로 결함은 무인증 원격 공격자가 특수 제작된 패킷을 영향받는 데몬 프로세스에 보내 상승된 권한으로 코드를 실행할 수 있게 한다. 같은 게시판에서 고위험 다수를 포함한 23건의 추가 취약점도 함께 수정됐다.

  • 핵심 취약점: CVE-2026-73749 — ArubaOS-CX 데몬의 잘못된 입력 처리로 인한 버퍼 오버플로, 무인증 원격 RCE — 유지보수 종료(EOM) 버전도 내부 발견 치명적 이슈 수정 대상에 포함
  • 주요 추가 결함: CVE-2026-73751(저권한 인증 사용자가 웹 관리 인터페이스로 OS 명령 실행), CVE-2026-73752(인접 네트워크 무인증 공격자가 API 엔드포인트로 임의 파일 쓰기 → RCE), CVE-2026-73753(저권한 사용자 CLI 조작으로 권한 상승), CVE-2026-73782(인접 네트워크 무인증 공격자의 포맷 스트링 결함으로 임의 코드 실행) 등 CVSS 8.1~8.8 고위험 다수
  • 영향: 대기업·정부기관·대학·의료·데이터센터·서비스 제공업체에서 쓰이는 ArubaOS-CX 스위치 — 현재 알려진 실전 악용·공개 PoC는 없으나 고정 릴리스로의 업그레이드를 강력 권고
