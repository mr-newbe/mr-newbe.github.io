1. npm ‘tensorlake’ 패키지 침해 — AI 에이전트 자격증명을 노리는 Shai-Hulud 웜이 다시 돌았다

Tensorlake 애플리케이션·샌드박스·클라우드 서비스용 TypeScript SDK인 npm 패키지 tensorlake가 ChainDrop / Shai-Hulud 공급망 공격으로 침해됐다. 악성 버전 0.5.144에는 자격증명을 수집하고 시크릿을 유출하며 지속성을 심는 난독화된 웜이 들어 있었다.

  • 유포 경로: 유지관리자(maintainer) 명의로 tensorlakeai/tensorlake 메인 브랜치에 악성 파일이 푸시된 뒤(10월 7일 01:20 UTC 첫 커밋), 하루 뒤 릴리스 워크플로가 0.5.144를 npm에 게시했다. 현재 해당 버전은 npm 레지스트리에서 내려갔다.
  • 동작 체인: preinstall 훅 → package/lib/setup.mjs(난독화 로더) → Bun 런타임으로 Math_Symbol.js(탈취·자기복제 웜) 실행. 로컬 파일·CI 환경·Kubernetes·HashiCorp Vault 전반의 자격증명을 긁어 HackBrowserData 바이너리를 떨어뜨린다.
  • 표적 자산: npm 토큰, GitHub 토큰, AWS 자격증명·시크릿, SSH 키, .env, 크립토 지갑, 메시징 앱 데이터, 그리고 Anthropic Claude·Cursor·Kiro·Windsurf·Zed의 설정 및 MCP 파일. 단일 API 키 탈취를 넘어 ‘실행 프로세스가 접근 가능한 모든 시크릿’이 노출된다.
  • C2·지속성: 이더리움 컨트랙트로 C2(iseekaigogo[.]com)를 해석하고 GitHub를 폴백으로 써서 탈취 데이터를 공개 저장소(“Shai-Hulud: Here We Go Again”)에 스테이징한다. 토큰 회수를 감시하는 ‘인질 토큰’ 모니터가 Invoke-Expression으로 파괴적 루틴을 실행할 수 있다.
  • 전파·대응: 피해자의 게시 아이덴티티로 패키지를 재배포하며 Sigstore 프로버넌스를 위조한다. .claude/settings.json·.vscode/tasks.json을 심어 Claude Code/VS Code에서 프로젝트를 여는 순간 다시 실행된다. 설치자는 즉시 제거하고 모든 토큰을 회전해야 한다.

2. Rabby·OKX 지갑로 위장한 악성 Firefox 확장 16종 — 복구 구문·개인키 탈취

보안 연구진이 크립토 지갑 복구 구문(mnemonic)과 개인키를 탈취하는 Mozilla Firefox 확장 16종을 발견했다. 확장들은 지갑 포털·데스크톱 유틸리티·브라우저 도구로 위장하지만, 지갑 가져오기(import) 흐름에서 복구 구문과 개인키를 가로채 공격자 인프라로 전송한다.

  • 구성: 16종 중 4종은 Rabby Wallet, 나머지는 OKX Wallet 복제본. 이름은 목록 공개(vibe-kit-tool, clean-file-bar, manager-team 등)됐다.
  • 유출 경로: 한 종을 제외한 전부가 Cloudflare Workers 도메인 *.icy-star-f45c.workers[.]dev로 접속해 복구 구문·개인키를 빼낸다.
  • 변종 지속: 2026년 8월 1차 웨이브의 연장선으로, 패키지 이름·버전·확장 ID·설명·표현 계층만 돌려쓰고 지갑 인터페이스·자격증명 처리 로직·네트워크 인프라는 재사용한다.
  • 대응: 10월 5일 기준 전부 스토어에서 제거됐다. 실제 복구 구문이나 개인키를 입력한 사용자는 침해로 간주하고, 깨끗한 시스템에서 새 지갑을 생성해 자산을 이전해야 한다.

10. [트렌드] 랜섬웨어가 산업 인프라로, 공격은 AI 속도로 — ‘운영 중단’이 새 비용 지표

오늘 게시물의 사건·취약점 블록은 서로 다른 사건처럼 보이지만 뿌리는 하나다. Qilin의 일본 클라우드 타격(4번 항목), CISA가 모니터링하는 산업제어 시스템(CPS), 그리고 AI가 앞당기는 공격 속도가 같은 방향을 가리킨다.

  • 운영 환경이 곧 표적: Claroty가 16개 산업·40여 개국 리더 2,000명을 조사한 결과 CPS 운영자의 58%가 지난 12개월간 운영 환경에 영향을 준 사이버 공격을 겪었다. 평균 운영 중단은 3일, 사고당 평균 재무 손실은 $1.04M(직원 1만 명 이상 조직은 $2.25M). 응답자의 약 10%는 8~30일 중단을 보고했다.
  • 3자 접근이 최대 리스크: 응답자의 75%가 3자 접근과 연관된 운영 영향 사고를 최소 한 번 경험했고, 49%는 3자 연결을 부분적으로만 또는 전혀 모니터링하지 않는다고 답했다. IT·OT 보안이 완전히 통합됐다는 응답은 16%에 불과하다.
  • 에너지·재생에너지 노출: 유럽의 태양광·재생에너지 제어 시스템 약 8,000개가 인터넷에 노출돼 있다는 연구가 나왔고, Centrii는 국가 배후 접근과 재생에너지 공급망 리스크가 에너지 부문 재무 노출을 키운다고 경고했다.
