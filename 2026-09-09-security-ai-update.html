1. Microsoft 9월 Patch Tuesday 역대 최대 규모 — 966~974개 취약점 패치, 야생 악용 제로데이 2종 포함

마이크로소프트가 9월 패치 화요일(현지 9월 8일)에 역대 최대 규모의 보안 업데이트를 발표했다. BleepingComputer 집계로 패치 화요일 당일 발표분만 966개, SecurityWeek·Krebs on Security는 약 974개(거의 1,000개)로 기록했다. 이는 종전 대규모 릴리스였던 7월 570개, 8월 400개를 크게 웃도는 수치로, MS가 AI 기반 취약점 탐지 시스템을 도입해 더 많은 결함을 식별하게 된 영향이 큰 것으로 분석된다.

  • 제로데이 1 — CVE-2026-81963: Windows Update Stack 권한 상승(improper link resolution/link following) — 로컬 공격자가 SYSTEM 권한 획득 가능, Romain Deperne와 MSTIC이 신고
  • 제로데이 2 — CVE-2026-85880: Windows Advanced Local Procedure Call(ALPC) 권한 상승 — 야생 악용 확인됨
  • 집계 기준: 이달 초 별도로 수정된 204건(Entra ID, Copilot Studio, Azure Cosmos DB, Microsoft Edge, Fabric, Power Automate 등)은 제외된 수치
  • 권고: Windows 11 누적 업데이트(KB5124008·KB5122880), Windows 10 ESU(KB5122878) 포함 즉시 적용 필요

2. Adobe, 악용 중이던 Magento 제로데이 CVE-2026-75650(CVSS 10.0) 패치 — 'StyleSmuggler'가 Rust 백도어·PHP 웹셸 배포 (9/6 보도 후속)

Adobe가 Adobe Commerce·Magento Open Source의 최대 심각도(CVSS 10.0) 제로데이 CVE-2026-75650을 수정하는 패치를 발표했다. Sansec이 9월 4일 22:20 UTC 첫 악용을 확인하고 'StyleSmuggler'로 명명한 이 결함은, Magento 자체의 템플릿 처리·의존성 주입(DI) 코드를 무인증 원격 코드 실행(RCE) 체인으로 전환한다. 지난 9월 6일 포스트에서 '패치 전 제로데이 악용'으로 다룬 사건의 후속이다.

  • 악용 방식: Rust 기반 Linux 백도어(외부 서버 연결 후 명령 대기) 및 PHP dropper를 통한 임의 PHP 실행 웹셸 작성 확인
  • 공격 속도: 네덜란드 Disrex가 관리하는 Magento 서버는 첫 StyleSmuggler 악용 보고(9/4) 50분 만에 침해됨
  • 허니팟 관측: Previdian 텔레메트리상 9월 7일 이후 중국·루마니아 IP 2개에서 12회 악용 시도가 있었으나 모두 실패
  • 규모: Adobe는 이번 패치에서 Commerce/Magento 포함 총 170개 이상 취약점 수정

3. Liquid Network 공격자, 탈취한 3,400 BTC(약 2억 6,300만 달러) 반환 — 598 BTC(약 4,700만 달러)는 미반환, 네트워크 여전히 중단

9월 6일 비트코인 사이드체인 Liquid Network에서 약 3,967 BTC(약 2억 6,300만 달러)가 탈취된 가운데, 공격자가 다음 날 3,400 BTC를 되돌려줬다. 약 598.5 BTC(약 4,700만 달러)는 아직 반환되지 않았으며 네트워크는 일시 중단 상태여서 보유자들은 L-BTC를 비트코인으로 되돌릴 수 없다.

  • 원인: SideSwap은 Liquid가 구동하는 소프트웨어 Elements의 버그로 해당 출금에 쓰인 L-BTC가 생성됐다고 설명 — 자체 시스템·키는 침해되지 않음, Blockstream도 브리지 노드는 손상 없었다고 밝힘
  • 블록체인 협상: 공격자는 트랜잭션에 "we are whitehats. contact us on chain" 메시지를 남기고 결함 수정·전 노드 패치를 요구 → Blockstream이 브리지 노드 패치를 서명 메시지로 확인 → 9월 7일 PGP 암호화 메시지(1,000 sat) 후 38분 만에 3,400 BTC 반환 확인
  • 잔여 물량: JAN3 CEO Samson Mow는 미반환분을 약 598 BTC로 집계 — Blockstream이 그룹과 접촉 중이며, 재시작 확정 전까지 peg-in 주소로 BTC를 보내지 말라고 경고
  • 논란: Ledger CTO Charles Guillemet은 협상된 '몫'이 남은 형태를 두고 화이트햇 라벨에 이의 제기

4. FreeIPA 결함 체인 — 로그인 이력 없는 익명 클라이언트가 '재사용 가능한 관리자 Kerberos 자격증명' 생성 (Red Hat)

Red Hat이 FreeIPA의 결함 체인을 공개했다. Linux 도메인 전역의 로그인 인증과 ID 관리를 담당하는 FreeIPA(389 Directory Server 기반 LDAP 저장소)에서, 한 번도 로그인한 적 없는 클라이언트가 임의의 Kerberos ID를 만들어 administrators 그룹에 도달하고 재사용 가능한 관리자 자격증명을 생성할 수 있다.

  • 체인 구성: 389 Directory Server 접근제어 엔진의 무인증 쓰기 결함(CVE-2026-76560, CVSS 7.5) + FreeIPA가 기본 배포하는 규칙 — 개별로는 조건부지만 FreeIPA 순정 설치에선 그대로 성립
  • 선행 결함: 실제 admin 계정 사칭은 CVE-2026-13097 수정(FreeIPA 4.13.3)으로 차단됐으나, 근본적인 무인증 쓰기는 남아 공격자가 고른 다른 이름으로 동일한 결과 도달
  • 검증: Red Hat이 순정 FreeIPA 4.13.1 컨테이너 이미지에서 체인을 재현하고 관리자 전용 명령으로 결과 확인 — 실제 공격 사례는 보고되지 않음
  • 추가 영향: Windows 스타일 SID를 쓰는 환경에서는 관리자 Kerberos 티켓 획득까지 가능

5. ChatGPT 대화에 심은 프롬프트 한 줄, 사용자 Gmail 데이터를 다른 계정으로 유출 (Check Point Research)

Check Point Research가 ChatGPT 대화에 심은 단일 지시문(planted instruction)이 사용자 질문에는 정상적으로 답하면서 백그라운드에서는 연결된 Gmail 데이터를 읽어 제2의 ChatGPT 계정으로 은닉 채널을 통해 전달하는 공격 PoC를 공개했다.

  • 은닉 채널: ChatGPT 데이터 분석용 Python 컨테이너들은 외부 인터넷 대신 내부 JFrog Artifactory 인스턴스에서 패키지를 받는데, 컨테이너가 가진 읽기 자격증명으로 캐시 파일에 '속성(properties)' 첨부·조회 가능 — 속성은 계정별로 격리되지 않아 계정 A 컨테이너가 기록한 값을 계정 B 대화에서 읽어내는 방식
  • 권한 문제: 연결된 앱의 'Important actions'가 기본 권한이라 Gmail 읽기 시 사용자에게 묻지 않음(설정에서 'Always ask'로 변경 가능)
  • 조치: OpenAI가 은닉 채널의 기반이 된 내부 서비스를 오프라인으로 전환했음을 CPR에 확인 — 사용자가 설치할 업데이트는 없음
  • 시사점: AI 에이전트에 부여된 기본 권한과 컨테이너 간 공유 인프라가 프롬프트 인젝션의 데이터 유출 경로가 될 수 있음을 재차 입증

6. '제로클릭' WeChat 웜 — 수신 전화 한 통으로 iPhone·Android 계정 탈취 후 자동 전파 (Calif)

보안 업체 Calif가 수신 전화(incoming call) 한 통만으로 WeChat 계정을 탈취하고 자동 전파되는 제로클릭 웜을 개발, 테스트 폰 3대에서 전파 시연에 성공했다고 공개했다. 피호출자가 전화를 받지 않거나 휴대폰을 건드리지 않아도 동작하지만, 발신자는 피해자의 WeChat 연락처에 등록된 상태여야 한다.

  • 영향: Calif는 Android 8.0.76/iOS 8.0.75(각각 8월 21일 릴리스보다 한 단계 아래)를 iOS 26.6 및 구형 Android에서 테스트
  • 대응: Calif가 7월 Tencent에 신고 → Tencent 8월 21일 릴리스(Android 8.0.77, iOS 8.0.76)로 완화하고 8월 28일 서버 측 차단을 확인 — "모든 사용자에 대해 익스플로잇 차단"이며 사용자 설치 조치는 불필요
  • 투명성 한계: 현재까지 CVE 번호·보안 권고가 없고, 피해 여부를 사용자가 알 방법도 없음 — 기술 세부는 추후 콘퍼런스에서 공개 예정
  • 규모: WeChat·Weixin 합산 MAU 14억 3,900만(2026년 6월 30일 기준) — 잠재 공격면이 매우 넓은 플랫폼

7. 자율 AI 멀티에이전트 공격 프레임워크, 6시간 만에 수천 개 자격증명 탈취 — Google TAG가 TeamPCP 활동 공개

Google Threat Intelligence Group(GTIG)이 금전 동기 위협 행위자 TeamPCP(일명 Altered Spider, UNC6780)가 자율적 멀티에이전트 공격 프레임워크를 이용해 6시간 이내에 수천 개의 자격증명을 수확하는 대규모 캠페인을 벌였다고 공개했다. AI 코딩 어시스턴트 등 독점 AI 자산을 노리는 다양한 동기의 공격자들이 증가하는 흐름의 일부다.

  • 공급망 침해: PyPI·npm·Docker Hub를 겨냥한 대규모 소프트웨어 공급망 손상으로 시작 — SANDCLOCK(Python 기반, Linux·Kubernetes 대상, 컨테이너 탈출 기능과 크립토 월렛·클라우드·개발자 자격증명 노림)과 후속 DUSTMAKER(크로스플랫폼 JavaScript, CI/CD 파이프라인 특화, 협박·탈취 중심) 배포
  • AI 표적화: AI 코딩 어시스턴트 워크스페이스 오염과 프롬프트 인젝션 기반 방어 회피는 DUSTMAKER에만 있는 신기법 — 탈취 자격증명은 직접 판매하거나 랜섬웨어·데이터 협박 그룹과 제휴해 현금화
  • AI 자산 탈취 확산: 중국 연계 UNC6508이 클라우드 환경을 침해해 로컬 오픈웨이트 LLM 인프라를 구축, AI 공급자 모니터링을 회피하는 사례와 모델·스킬·프롬프트·소스코드 탈취 협박, Google AI 모델(시각·오디오 이해, 이미지 생성·비디오 요약) 증류 공격도 관측
  • 시사점: AI가 공격 자동화의 '실행 계층'으로 자리잡는 동시에, AI 자체가 표적 자산이 되는 이중 위협 확인

8. 'DoppelCart' — 가짜 쇼핑몰 11만 9,000개로 카드정보 훔치는 사기 네트워크 적발 (Nebty)

사이버보안 업체 Nebty가 119,000개가 넘는 가짜 온라인 쇼핑몰로 구성된 대규모 카드정보 탈취 사기 네트워크 'DoppelCart'를 공개했다. 가짜 사이트들은 44,182개 브랜드를 사칭하며(브랜드당 평균 2개, 일부는 30개 이상 클론) 실제 브랜드 서버에서 에셋을 직접 로딩해 정교하게 위장하고, 최대 65% 할인을 미끼로 쇼핑객을 유인한다.

  • 데이터 탈취: 결제 페이지 코드가 카드번호·유효기간·CVV·카드 소유자명·이메일·전화·주소를 수집해 WebSocket으로 C2에 실시간 전송 — 은행이 발급한 1회용 확인 코드(OTP)까지 중계해 3-D Secure 등 보안 장치 우회
  • 피해 전가: 일부 가짜 상점은 사칭 브랜드의 정식 고객지원 주소를 노출해, 물건을 받지 못한 피해자가 실제 기업에 항의하게 만듦
  • 대응: 메인 호스팅 제공업체는 연락에 응답하지 않음 — Nebty는 기업이 사칭·브랜드 남용을 식별·조치할 수 있는 검색 가능한 DB를 공개
