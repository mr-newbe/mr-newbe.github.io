1. 브라질 뱅킹 멀웨어 'KREMLIN' — Chrome·Edge 확장으로 자격증명·세션 토큰 탈취

Elastic Security Labs가 브라질 은행을 사칭하는 신종 뱅킹 멀웨어 생태계 'KREMLIN'을 공개했다. 위협 행위자는 'REF9334'로 추적되며 최소 2025년 5월부터 활동해 왔다.

  • 감염 경로: 은행·인보이스·회사 문서로 위장한 JavaScript 파일을 사용자가 직접 실행 → 다단계 로더 → C++ 설치 프로그램 → Chrome/Edge 악성 확장 설치의 3단계 체인.
  • C2 은닉: 이더리움 스마트 컨트랙트를 데드드롭 리졸버(dead drop resolver)로 악용해 C2 주소와 페이로드 호스팅 위치를 동적으로 갱신 — 인프라 차단이 사실상 불가능.
  • 방어 우회: SentinelOne의 정상 바이너리(SentinelMemoryScanner.exe)로 DLL 사이드로딩을 수행하고, 'SentinelAgentCore.dll'을 사칭. VM/샌드박스 탐지 시 실행을 중단하며 CPU 2개·RAM 3GB 이하 환경을 회피.
  • 확장 신뢰 파괴: Secure Preferences를 조작하고 필요한 HMAC과 App-Bound 암호화 해시를 재생성해 Chromium 무결성 검사를 통과 — 브라우저 확장 신뢰 모델 자체가 우회됐다.

3. 중국 연계 해커, Chrome·Windows 제로데이 체인으로 NGO 공격 — 'GRIMWEDGE' 백도어 투입

Volexity는 중국 위협 클러스터 UTA0560이 Chrome·Windows의 최신 패치 취약점을 결합한 스피어피싱 체인으로 2026년 9월 1일 다수 NGO를 공격해 JavaScript 백도어 'GRIMWEDGE'를 유포했다고 밝혔다.

  • 패치 갭 악용: 두 Chrome 취약점의 수정이 오픈소스 Chromium 코드베이스에는 반영됐지만 안정 버전 Chrome 릴리스에는 포함되지 않아, 사실상 제로데이로 작동하는 이례적 상황이 발생.
  • 제2 행위자 동시 활동: APT31(JungleBamboo)도 같은 익스플로잇 체인을 사용해 로더 SUPERSTOMP → 자격증명 탈취 크롬 확장 'LONGTALE'(GemStone)을 배포. Google Gemini 확장(ID: ckiknalbeplpcpofpnabcnhjcegckfei)으로 위장.
  • LONGTALE 기능: 키로깅·폼 입력 수집, 쿠키·세션 탈취, 키워드 기반 화면 캡처, 약 30초 간격으로 키스트로크·쿠키·스토리지·방문 기록을 C2로 대량 유출.
  • 시사점: 같은 익스플로잇 체인을 여러 중국계 행위자가 거의 동시에 사용한 점은 익스플로잇이 재판매·유통됐거나 개발자가 Chromium 소스 변경을 역분석해 공급했을 가능성을 시사.

4. 'BambooToken' 멀웨어, MQTT 프로토콜로 Windows·Linux 동시 장악 — 3년간 미탐지

Lumen Black Lotus Labs가 MQTT(Message Queueing Telemetry Transport)를 C2 통신 채널로 쓰는 다중 플랫폼 멀웨어 'BambooToken'을 공개했다. 최소 2023년 2월부터 활동했고, 2026년 7월까지 공격이 확인됐다.

  • 표적: 아시아·남미 조직. VirusTotal에 업로드된 대부분의 샘플이 중국 IP 대역에서 제출돼 중국 및 인접국 사용자를 겨냥한 데이터 수집 캠페인으로 평가된다.
  • 침투 기법: Tendyron의 PKI USB 토큰 소프트웨어 'OnKey'(전 세계 1억 9천만 개 토큰 보급 주장)를 DLL 사이드로딩에 악용 — 코드 서명 인증서나 빌드 환경이 탈취된 것은 아니며, 사이드로딩에 취약한 정상 바이너리를 사용한 것으로 추정.
  • C2 특성: 경량 발행-구독 프로토콜인 MQTT를 사용해 탐지 회피. 2023년 Mustang Panda의 MQsTTang 이후 MQTT를 악용한 사례는 소수에 불과해 희소성이 높다.
  • 대응: 고보안 환경의 금융·정부용 인증 소프트웨어가 공격자의 '정상 바이너리'로 전락할 수 있음을 보여주므로, 애플리케이션 허용 목록과 비표준 포트(1883/8883) MQTT 트래픽 모니터링이 필요하다.

5. Cisco Secure Email Gateway 치명적 결함 CVE-2026-76461 (CVSS 9.8) — 실제 악용 중, CISA KEV 등록

Cisco가 Secure Email Gateway용 AsyncOS 소프트웨어의 치명적 취약점이 실제 공격에 악용되고 있다고 경고했다. CVSS 9.8로, 이메일 파싱 로직의 불충분한 입력 검증이 원인이다.

  • 공격 방식: 악성 SQL 구문이 포함된 조작된 이메일을 발송하는 것만으로 인증 없이 원격에서 기반 OS의 root 권한으로 임의 명령 실행이 가능하다.
  • 공식 대응 기한: CISA가 KEV(알려진 악용 취약점) 카탈로그에 등록하고 연방 민간 행정기관(FCEB)에 2026년 9월 17일까지 패치 적용을 요구 — 이번 주가 마감이다.
  • 부가 정황: Arctic Wolf는 2026년 8월 말 인터넷 노출 Fortinet VPN 어플라이언스를 겨냥한 대규모 자격증명 공격을 두 차례 파도로 탐지했다고 밝혀, 경계 장비 전반에 대한 스캔·무차별 대입이 동시다발적으로 진행 중이다.
  • 대응: 최신 AsyncOS로 즉시 업그레이드하고, 메일 게이트웨이의 아웃바운드 연결을 신뢰 IP로 제한하며, 알려진 악성 IP에서의 연결·다운로드 로그를 점검할 것.

6. [클라우드] GKE 'Fragnesia'(CVE-2026-46300) 컨테이너 탈출 + 노출된 Vite 개발 서버 대량 자격증명 탈취

관리형 클라우드 인프라와 개발 환경이 동시에 표적이 됐다. Google Kubernetes Engine(GKE)은 컨테이너 격리를 깨고 호스트 root를 획득하는 두 건의 결함을 조용히 공개했고, F5 Labs는 노출된 Vite 개발 서버를 스캔해 AWS·Azure 자격증명을 빼가는 캠페인을 공개했다.

  • Fragnesia: CVE-2026-46300 — 컨테이너 탈출 후 기반 호스트에서 root를 획득. 실제 운영 중인 GKE 표준(Ubuntu 노드 풀) 구성에 영향.
  • containerd 결함: GHSA-p7v4-vr35-mj6f(CRI 체크포인트-복원 경로)로, 아직 CVE 번호가 부여되지 않았으나 역시 실제 컨테이너 격리를 깬다.
  • Vite 대량 스캔: CVE-2026-39364(CVSS 8.2) — 인증 없이 쿼리 파라미터(?raw, ?import 등)를 조작해 server.fs.deny로 차단된 .env, *.crt 등의 파일을 HTTP 200으로 반환받아 유출. 2026년 8월 관측.
  • 피해 규모: 인터넷에 노출된 Vite 개발 서버에서 AWS·Azure 자격증명, 설정 파일, 인프라 상태(state) 파일까지 탈취 — 개발 서버가 프로덕션 클라우드 권한의 통로가 됐다. 개발 서버 외부 노출 중단과 자격증명 회전이 시급하다.
