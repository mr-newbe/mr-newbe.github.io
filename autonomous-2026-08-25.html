핵심 내용

PythonRobotics는 로보틱스 핵심 알고리즘을 최소한의 Python 코드(대부분 100줄 안팎)로 구현해 matplotlib 애니메이션과 함께 보여주는 교과서 동반 코드집이다. 로봇이 '내가 어디에 있는지'(localization) → '주변이 어떻게 생겼는지'(mapping) → '어디로 갈지'(path planning) → '어떻게 따라갈지'(path tracking) 판단하는 전 과정을 하나의 저장소에서 순서대로 배울 수 있다. 자율주행차도 본질적으로 같은 구조를 가진다.

  • Localization (위치 추정): 확장 칼만 필터(EKF), 파티클 필터, 히스토그램 필터 — GPS·IMU·라이다 센서 잡음 속에서 차량의 정확한 위치를 추정하는 기법
  • Mapping & SLAM: 라이다→그리드 맵 변환, k-means 객체 클러스터링, ICP 매칭, FastSLAM 1.0 — 지도 없이 스스로 지도를 만들며 위치를 추정하는 동시적 위치추정·지도작성
  • Path Planning (경로 계획): Dynamic Window Approach(DWA), 그리드 탐색(A*/Dijkstra), State Lattice, PRM, RRT, 5차 다항식 계획, Reeds-Shepp, LQR 기반 계획, Frenet 프레임 최적 궤적 — 도로 상황에 맞는 주행 경로를 생성하는 핵심 모듈
  • Path Tracking (경로 추종): Stanley 컨트롤(2005 DARPA 그랜드 챌린지 우승팀 Stanford가 실제로 사용), 후륜 피드백 제어, LQR 속도·조향 제어, MPC(모델 예측 제어), 비선형 MPC(C-GMRES) — 생성된 경로를 실제 조향·가속 명령으로 변환
  • 교육 중심 설계: 모든 예제가 단일 파일로 실행 가능하고, 애니메이션으로 알고리즘 동작을 시각화 — README에 'Use-case'·'Contribution' 가이드까지 갖춘 교재형 구성

시사점 및 결론

PythonRobotics는 "자율주행 = 인식 모델"이라는 편견을 바로잡아 주는 저장소다. 차량이 실제로 움직이려면 인식 결과를 바탕으로 어디로 갈지(계획)와 어떻게 갈지(제어)를 결정해야 하며, 그 알고리즘들(EKF→파티클 필터→SLAM→RRT/Frenet→Stanley/MPC)은 30년 넘게 다듬어진 고전이자 현장 표준이다. 30,000개가 넘는 스타는 단순한 인기를 넘어, 오픈소스 '교과서'가 학계·산업계 교육을 어떻게 바꿀 수 있는지를 보여주는 증거다. 입문자라면 이 저장소의 순서(위치 추정 → SLAM → 경로 계획 → 경로 추종)를 그대로 따라가며 각 알고리즘의 100줄 구현을 직접 돌려보는 것이, 최신 end-to-end 모델을 이해하기 전에 밟아야 할 가장 확실한 기초 공부가 된다.
