핵심 내용

2016년 NVIDIA의 DAVE-2는 "카메라 픽셀 → 조향각"을 학습해 사람이 만든 특징 없이도 차선을 따라가는 것을 보여줬다. 그러나 치명적인 구멍이 있었다. 그렇게 학습된 정책은 테스트 시점에 조종할 수 없다. 차선은 잘 따라가지만 "다음 교차로에서 우회전하라"고 지시할 방법이 없고, 목적지로 데려갈 수도 없다. CIL(Conditional Imitation Learning)은 이 문제를 "모방학습을 고수준 명령에 조건화(conditioning)하라"는 한 문장으로 다시 정의했다. 2017년 10월 arXiv에 올라온 이 논문이 오늘날 자율주행 모방학습의 인터페이스가 됐다.

  • 문제 정의 — "조종 불가능한 정책": 논문의 출발점은 성능이 아니라 사용성이다. 사람이 시연으로 학습한 정책은 지각-운동 협응(sensorimotor coordination)은 배우지만, 의사결정(어디로 갈지)은 배우지 못한다는 것. 저자들은 이 분업을 "chauffeur(운전기사)"에 비유한다. 지각과 조작은 네트워크가, 경로 지시는 명령이 담당한다.
  • 명령 조건부 정책: 관측 o = ⟨이미지 i, 계측 m(속도)⟩에 명령 c를 더해 조건화한다. 명령은 원-핫 4종 — continue(차선 유지), left(다음 교차로 좌회전), straight(직진), right(우회전). 출력은 조향 + 가속의 연속 2차원이며, 정책은 사람이 개입한 시점의 조작을 무시하고 운전자가 제공한 신호만 학습한다(recovery 데이터 처리).
  • 두 아키텍처의 정면 비교 (논문의 핵심 기여): ① command input — 명령을 영상·계측과 함께 입력 벡터로 넣는다. ② branched — 명령이 스위치 역할을 해 명령별 전용 서브모듈을 선택한다. 이미지 모듈은 8개 conv + 2개 fc, 입력 해상도 200×88로, NVIDIA DAVE-2식 3카메라 구성(전방 + 좌우 시프트)을 차용했다. 결론은 명확했다 — branched가 모든 조건에서 우세, 즉 "명령을 입력으로 주는 것"만으로는 부족하고 네트워크를 명령별로 분기시키는 구조가 필요하다.
  • 소량의 노이즈 주입(recovery)이 정책을 살린다: 전체 학습 데이터 2시간 중 사람이 개입해 복구한 구간은 약 12분(10%)뿐이었다. 그런데 이 소량의 노이즈 데이터를 뺀 모델은 성공률이 급락했다(Town 1 88%→56%). 논문은 "강한 노이즈를 주입해 데이터를 모으는 일은 운전자에게 매우 힘들었지만, 적은 양이 놀랄 만큼 효과적이었다"고 기록한다.
  • 데이터 증강이 일반화를 결정한다: 대비·밝기·색조 변환과 노이즈 추가를 온라인으로 적용했다. 효과는 극적이었다 — 학습에 한 번도 쓰지 않은 Town 2에서 증강 없는 모델은 단 하나의 에피소드도 완주하지 못했다(성공률 0%). 반면 증강을 넣은 branched 모델은 64%를 기록했다.
  • 시뮬레이션 결과 (Table I, Town 1 / Town 2 성공률): 비조건부 20% / 26%, goal-conditional(목표점 벡터 조건화) 24% / 30%, CIL branched 88% / 64%, CIL command input 78% / 52%. 여기에 절제 실험까지 — 노이즈 없음 56% / 22%, 증강 없음 80% / 0%, 얕은 네트워크 46% / 14%. "명령을 조건으로 넣는가"가 성공률을 3배 이상 바꾼다는 것이 이 표의 요지다.
  • 실차 검증 — 1/5 스케일 로봇 트럭 (Table II): NVIDIA TX2에서 실시간 구동, 중앙 웹캠 영상 + 리모컨 3방향 스위치(left/straight/right)로 명령을 준다. 주거지역 14개 교차로 경로 결과 — branched missed turn 0% · 개입 0.67회 · 2분19초, command input 11.1% · 2.33회 · 4분13초, 노이즈 없음 24.4% · 8.67회 · 4분39초, 증강 없음 73% · 39회 · 10분41초(트럭이 부서질 위험 때문에 1회만 실행). 시뮬레이터의 순위가 실차에서 그대로 재현됐다.
  • 새 환경 일반화: 학습은 맑은 날씨, 평가는 흐린 날씨에서 이뤄졌다. 나아가 외관이 완전히 다른 3개 신규 환경에서도 트럭은 차선을 유지하고 명령에 계속 반응했다 — 조건부 정책이 "명령 채널"을 별도로 유지한다는 증거다.

왜 유명한가 / 활용 가치

  • 1,356회 인용 (2026-09-16, Semantic Scholar / OpenAlex 1,115회): 단순히 성능을 올린 논문이 아니라 "명령 조건부 + 모방학습"이라는 문제 설정 자체를 만든 논문이다. 이후 CARLA 기반 end-to-end 연구 대부분이 이 설정을 그대로 물려받았다.
  • DAVE-2 (2026-08-22 포스팅)의 한계를 정면으로 해결했다: DAVE-2가 "픽셀에서 조향을 배울 수 있다"를 증명했다면, CIL은 "하지만 그 정책은 지시를 받아야 쓸모가 있다"를 증명하고 해법을 제시했다. 두 논문을 나란히 읽으면 end-to-end 주행 10년의 문제의식이 한 번에 정리된다.
  • CARLA (2026-09-09 포스팅)와 함께 표준 연구 환경을 완성했다: 시뮬레이터(CARLA) + 기준 문제(명령 조건부 주행) + 공개 코드(carla-simulator/imitation-learning ⭐484, MIT) + 평가 규약(교차로 명령·성공률)이 한 세트로 공개됐다. 오늘날 CARLA 리더보드 지표의 문법적 뿌리가 여기 있다.
  • 계보가 이 블로그의 최근 포스팅과 그대로 이어진다: CIL → Learning by Cheating(CoRL 2019, 727회) → CILRS(ICCV 2019) → TransFuser(2026-08-26 포스팅) → ChauffeurNet(2026-09-08 포스팅) → LMDrive(2026-09-12 포스팅, "자연어 지시"를 명령으로) → Alpamayo 1(2026-09-04 포스팅). 즉 "의도(명령)를 조건으로 주행 정책을 제어한다"는 축은 2017년부터 지금의 VLA 계열까지 끊기지 않는다.
  • 실험 설계 교훈이 지금도 유효하다: 노이즈 주입(recovery)과 온라인 데이터 증강의 효과를 절제 실험으로 분리해 수치로 제시했다. "증강 없으면 신규 도시 성공률 0%"는 모방학습 실험을 설계할 때 가장 먼저 인용되는 근거다.
  • 재현·교육 비용이 낮다: 공개 코드(MIT) + 경량 아키텍처(8 conv + 2 fc) + 4개 명령이라는 최소 인터페이스 덕분에, CARLA만 설치하면 오늘날에도 개인이 그대로 재현할 수 있다. end-to-end 주행을 처음 시작할 때 베이스라인으로 삼는 것이 표준 관행이다.

시사점 및 결론

CIL의 진짜 기여는 새 네트워크가 아니라 인터페이스였다. 모방학습의 목표를 "사람과 같은 수준의 주행"이 아니라 "사람이 지시할 수 있는 주행"으로 재정의한 것이다. 조향을 흉내 내는 모델은 목적지로 데려다줄 수 없지만, 명령에 조건화된 정책은 차량을 원하는 방향으로 유도할 수 있다 — 논문이 쓴 그대로 chauffeur다. 가지치기(branching) 구조와 소량의 복구 데이터, 온라인 증강이라는 세 가지 실무적 결론도 함께 남겼고, 그중에서도 "증강 없이는 새로운 도시에서 0%"라는 결과는 모방학습의 성능이 데이터 양보다 커버리지와 복구 데이터에서 나온다는 것을 보여준다. 9년이 지난 지금도 같은 골격이 반복된다 — LMDrive는 명령을 자연어로, Alpamayo는 인과 추론으로 확장했지만, "고수준 의도를 조건으로 넣고 지각-운동은 네트워크에 맡긴다"는 분업은 변하지 않았다. 한 줄 요약: "조향을 배우게 하지 말고, 명령을 받는 정책을 배우게 하라" — end-to-end 주행의 인터페이스를 정의한 논문이 CIL이다.
