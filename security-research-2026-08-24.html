제목: Utility Under Attack: Agent Memory Poisoning and the Limits of Content Screening and Provenance Ranking
저자: Arulnidhi Karunanidhi
분야: cs.CR / AI 에이전트 보안 (메모리 중독)

연구 배경

장기 메모리(persistent memory)는 LLM 에이전트가 세션 간 맥락을 유지하는 핵심 기능이지만, 한번 저장된 잘못된 정보는 이후 모든 세션에서 지속적으로 재검색된다 — "거짓이 저장되면 거짓이 영속화된다". 기존 연구는 주로 프롬프트 인젝션·트리거 기반 공격에 집중했으나, 본 논문은 특별한 트리거나 최적화 없이 평범한 문장으로 작성된 단순 거짓 주장만으로 에이전트 메모리를 중독시킬 수 있는지, 그리고 현재의 방어 기법(콘텐츠 스크리닝, 출처 가중 검색)이 이를 막을 수 있는지를 측정한다.

핵심 내용

  • 공격 실효성: LongMemEval 말뭉치의 1.2%만 중독시켜도 에이전트 정확도가 0.850 → 0.300으로 급락 — 단일 패스로 생성한 평범한 거짓 주장만으로 달성되며, 인스트럭션·트리거·리트리버 최적화가 전혀 필요 없음
  • 콘텐츠 스크리닝의 한계: 간접 프롬프트 인젝션 대비 0.832 recall·1.5% 오탐률을 달성한 4단계 작성 시점(write-time) 스크리닝 파이프라인도 중독된 메모리 360건 중 0건만 탐지 — "거짓 주장과 참 주장의 구분"은 텍스트 자체만으로는 불가능하며 외부 근거(grounding)가 필수적이라는 경계를 실증
  • 출처 가중 검색의 딜레마: 현재 배포된 가중치는 방어 효과가 통계적으로 무의미(p=0.80)했고, 강한 가중치는 신뢰할 수 없는 콘텐츠를 배제할 때만 효용을 회복(정확도 0.3167 → 0.7000). 그러나 정답이 담긴 증거 자체가 신뢰할 수 없는 출처에서 오면 증거 재검색률이 0, 정확도 0.0417로 붕괴
  • 제안: 가산적(additive) 출처 페널티는 어떤 가중치로도 유효한 설정이 없다고 결론 — 대신 검색 시점의 "점유 상한(bounded occupancy) 제약"으로 신뢰할 수 없는 콘텐츠의 메모리 점유 비율을 제한하는 방향을 제안하며, 하네스·말뭉치·실행 리포트를 공개

보안 시사점

  • 장기 메모리를 가진 에이전트는 "지속성 있는 거짓 정보"라는 새로운 공격 표면에 노출됨 — 1회성 입력 검증만으로는 부족하고, 메모리 쓰기(write) 경로에 대한 근거 기반(grounded) 검증이 필요
  • 콘텐츠 스크리닝·프롬프트 인젝션 탐지 성능이 높다고 해서 거짓 정보 탐지로 이어지지 않음 — 지시문(instruction) 탐지와 사실성(factuality) 검증은 별개의 문제로 설계해야 함
  • 출처 가중 검색은 공격 저항성과 정당한 비신뢰 콘텐츠 활용 사이에서 근본적 트레이드오프를 가짐 — 단순 가중치 튜닝이 아닌 메모리 점유율·격리(containment) 정책 같은 구조적 방어가 유망
  • 에이전트가 웹 콘텐츠·이메일·도구 출력을 메모리에 축적하는 워크플로우가 확산될수록, 메모리 수명주기(쓰기·검색·만료) 전반의 보안 설계가 필수적

결론

이 연구는 "아무런 최적화 없는 평범한 거짓 문장"만으로도 에이전트 장기 메모리를 효과적으로 중독시킬 수 있음을 보여주며, 현재 산업계가 채택한 콘텐츠 스크리닝과 출처 가중 검색이 모두 이 공격에 취약함을 정량적으로 입증했다. 텍스트 자체만으로 거짓을 판별할 수 없다는 한계를 인정하고, 외부 근거 검증과 메모리 점유 상한 같은 구조적 방어로 패러다임 전환이 필요함을 시사한다.
