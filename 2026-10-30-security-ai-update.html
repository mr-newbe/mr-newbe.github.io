1. 바이낸스, 최대 58억 달러 탈취 의혹 — 테더·서클 23억 달러 동결

가상자산 거래소 바이낸스가 최대 58억 달러 규모의 자산 탈취 의혹을 조사 중이다. 확인될 경우 2025년 2월 북한 연계 조직이 저지른 바이비트(Bybit) 15억 달러를 넘어 역대 최대 암호화폐 해킹이 된다. 바이낸스 측은 "사용자 자금은 완전히 안전하다"며 공식 채널을 통해서만 업데이트하겠다고 밝혔고, 창업자 자오창펑(CZ)은 X에서 "해킹으로 보인다"고 언급했다.

  • 자금 이동 정황: 블록체인 분석에 따르면 'Binance 14' 핫월렛에서 64개 토큰 25억 3,000만 달러가 신규 이더리움 주소로 이동했고, 24초 뒤 두 번째 지갑에서 1억 7,440만 달러가 추가됐다. 이후 세 번째 핫월렛의 7억 8,000만 USDC까지 같은 주소로 보내져 추적 총액은 약 34억 8,000만 달러로 늘었다.
  • 추적 현황: 아캄 인텔리전스는 'binance-hacker-1029' 엔터티로 55개 주소를 묶어 약 57억 8,000만 달러(USDT 17.7억·BTC 14.4억·ETH 8.76억·USDC 8.23억)를 추적 중이다. 이더스캔은 최초 수신 주소에 'Binance Hot Wallet Exploiter 2' 라벨과 Exploit·Heist 태그를 붙였다.
  • 스테이블코인 동결: 테더가 15억 6,700만 USDT, 서클이 8억 USDC를 동결해 23억 달러 이상이 묶였다. 서클은 수사기관과 공조 중이라고 밝혔다.
  • 주의: 57억 8,000만 달러는 추적 지갑의 보유 자산 합계이지 확인된 피해액이 아니다. 바이낸스는 아직 무단 이체 여부·침해 경로·총 피해액을 확정하지 않았으므로, 공식 발표 전까지 사칭 복구·에어드랍 링크가 활개칠 구간이다.

2. 일본항공, 아마데우스 예약시스템 침해로 9만 2,000명 정보 유출 — 3년간 노출

일본항공(JAL)이 예약·발권·체크인을 담당하는 아마데우스(Amadeus) 승객서비스시스템(PSS) 침해로 고객 약 9만 2,000명의 정보가 유출됐다고 공지했다. 아마데우스는 10월 23일 JAL에 통보했고, 무단 접근 기간은 2023년 8월 10일 ~ 2026년 9월 23일로 3년 넘게 이어졌다.

  • 유출 항목: 약 9만 명은 예약번호(PNR)·이름·항공편 날짜·구간·좌석 등급. 나머지 2,000명은 여기에 이메일·전화번호·여권번호·국적·상용고객(FPP) 번호·항공권/좌석 번호까지 포함됐다. 신용카드 번호와 비밀번호는 유출되지 않았고, 현재까지 악용 정황은 없다고 밝혔다.
  • 원인: 아마데우스는 10월 1일 자사 '여행 예약 표시(display) 환경'의 취약점을 발견해 공지했고, 당시 랜섬웨어 조직의 악용 정황은 없다고 설명했다. JAL은 아마데우스가 보안 조치를 완료했으며 운항에는 영향이 없다고 덧붙였다.
  • 파급 범위: 아마데우스는 400개 이상 항공사, 210개 공항 운영사, 34개 크루즈·페리, 200만 개 호텔이 쓰는 항공 IT 대표 공급사다. 즉 이 취약점은 JAL 한 곳의 문제가 아니라 예약 인프라 공통 리스크이며, 다른 항공사 고지가 순차적으로 나올 가능성이 높다.
  • 일본 연쇄 유출: 소니 ISP(258만 건), KDDI, 니혼콜롬비아, 타임즈카, GMO 오나마에에 이어 JAL까지 — 올해 일본은 '유출 러시' 상태다. 여권번호가 포함된 2,000명은 항공사 사칭 피싱·보이스피싱의 정밀 표적이 되므로, JAL 공식 앱·홈페이지 외 채널의 '환불·보상' 안내는 전부 의심해야 한다.

3. 텔레그램 안드로이드, 통화 수락만으로 코드 실행 — 12.10.4에서 조용히 수정

보안 스타트업 NebuSec이 텔레그램 안드로이드 앱의 통화 처리 결함을 공개했다. 공격자는 평범한 텔레그램 계정 하나로 피해자에게 전화를 걸고 상대가 수락하기만 하면 앱을 벗어나 안드로이드로 탈출할 수 있다. 정보 유출 버그와 안드로이드 루트 익스플로잇을 연쇄하면 메시지·마이크·카메라까지 완전 장악된다. 텔레그램은 12.10.4(9월 말)에서 수정했고 NebuSec은 10월 29일 공개했다.

  • 기술 원인: 통화 상태를 주고받는 MediaState 메시지 파싱에서 필드 누락을 처리하지 않아 엉뚱한 메모리를 읽는다. 회전(rotation) 값을 검사한 뒤 실제로는 존재하지 않을 수 있는 비디오 상태 필드를 읽는 구조로, 12.10.4는 올바른 필드에서 값을 읽도록 바꿨다.
  • 영향 버전: 8.6.2 ~ 12.10.3(2022년 3월 ~ 2026년 9월). ARM64 기기 사설 통화로 확인됐고, iOS·데스크톱·그룹 통화에 대한 직접 영향 증거는 아직 없다. 공유 라이브러리 tgcalls는 4월 21일 'Fix camera rotation'으로 이미 수정돼 iOS 12.7·데스크톱 7.0.1에는 반영됐다.
  • CVE 없음: NebuSec은 9월 26일 신고했지만 텔레그램은 RCE로 이어질 수 있다는 판단에 동의하지 않아 CVE 미발급·바운티 미지급으로 끝났다. 공개 자료도 데모 영상과 회사 설명뿐이고 기술 상세 문서는 없다 — 심각도 평가가 갈리는 지점이다.
  • 즉시 조치: 설정 하단에서 버전이 12.10.4 이상인지 확인. 통화 개인정보 설정을 '아무도 안 함(Nobody)'으로 바꾸거나 모르는 통화를 거절하는 것만으로 차단된다. 국내 사용자 비중이 높은 앱인 만큼 자동 업데이트 여부를 직접 확인할 가치가 있다.

4. Gitee 공개 저장소에서 '지금도 유효한' 클라우드·AI 자격증명 2만 6,400개 발견

독립 연구자 Ben Zimmermann이 중국 코드 호스팅 Gitee의 공개 저장소 725만 개를 한 달간 스캔해, 실제로 인증에 성공한 자격증명 2만 6,400개를 찾아냈다(10월 28일 공개). 대부분 클라우드와 AI 서비스 키였고, 알리바바 클라우드 AccessKey 쌍 9,473개가 최대였다.

  • 서비스별 분포: 유튜브 API 키 3,805개, DeepSeek 키 3,170개, 즈푸(Zhipu) BigModel 1,489개, OpenAI 키 1,348개, 그 외 GitHub·AWS·GCP·Gemini 소수. 이 중 하나는 "주요 엔터프라이즈 AI 플랫폼의 조직 관리자(org-admin) 자격증명"이었다고 밝혔지만 플랫폼 이름은 공개하지 않았다.
  • 왜 '유효'가 핵심인가: TruffleHog와 Kingfisher 두 스캐너로 발급처에 직접 인증을 시도해 성공한 것만 집계했다. 전체 커밋 이력을 읽었기 때문에 코드에서 지운 키도 포함된다. 커밋 연도 기준 1만 2,242개가 2025년이고, 2000년대 후반 키도 남아 있었다.
  • 도구별 편차: TruffleHog 1만 2,737개, Kingfisher 1만 4,664개를 찾았지만 양쪽 모두가 찾은 건 1,001개뿐. 스캐너 하나만 돌리면 절반을 놓친다는 뜻으로, 시크릿 스캐닝 파이프라인 설계에 바로 반영할 수치다.
  • 실무 대응: 공개 저장소에 한 번이라도 올라간 키는 코드 삭제·히스토리 재작성으로 회수되지 않는다. ① 발급처에서 즉시 로테이션·비활성화 ② 알리바바 ActionTrail(90일)·OSS/SLS 개별 로그로 이상 호출 확인 ③ OpenAI는 사용 한도 설정 ④ 유튜브/GCP 키는 API 제한(restriction) 부여. 리포지토리 삭제로 끝났다고 생각하는 팀이 여전히 가장 위험하다.

5. 시스코 ASA·FTD 제로데이(CVE-2026-76418) 실제 악용 — SSL VPN 5만 1,000대 인터넷 노출

시스코가 Secure Firewall ASA·FTD의 서비스거부(DoS) 제로데이 CVE-2026-76418(CVSS 8.6) 패치를 배포했다. PSIRT가 이달 초 실제 악용 정황을 확인했다고 밝혔지만, 표적 조직·공격자·침해지표(IoC)는 공개하지 않았다. 섀도서버는 인터넷에 노출된 시스코 ASA SSL VPN 장비를 5만 1,000대 이상으로 집계한다.

  • 취약 조건: 설정에 'webvpn' 키워드가 있고 최소 한 인터페이스에서 SSL VPN이 켜진 장비. 터널 그룹에 2차 인증(secondary authentication)이 설정된 상태에서의 로직 오류가 원인이며, 무인증 원격 공격자가 조작된 요청을 보내면 장비가 예고 없이 재부팅된다.
  • 완화책: 시스코는 우회 설정을 제공하지 않는다. 즉시 패치가 어렵다면 DefaultWEBVPNGroup 또는 사용자 정의 터널 그룹의 2차 인증을 비활성화하는 것이 유일한 임시 조치다. CISA는 10월 29일 KEV에 추가하고 연방기관 패치 기한을 11월 1일로 못박았다.
  • 반복되는 시스코 악용: 2025년 9월 ArcaneDoor 연계 CVE-2025-20362·20333(긴급지시 ED 25-03, 24시간 내 조치) → 2026년 8월 CVE-2026-20349 → 이달 초 Secure Email Gateway CVE-2026-76519(무인증 root RCE) → 이번 ASA/FTD까지. 2021년 11월 이후 CISA가 '실제 악용'으로 지정한 시스코 취약점은 101건이다.
  • 실무 우선순위: 엣지 VPN 장비는 패치 주기가 길고 재부팅 창의 제약이 크다. ① 자산 인벤토리에서 webvpn 설정 장비 추출 ② 2차 인증 사용 여부 확인 후 임시 완화 ③ 재부팅 이력·비정상 TLS 핸드셰이크 로그 점검 ④ 가능하면 유지보수 창에 즉시 업그레이드.

6. Volt Typhoon 연계 의심 UAT-11473, SD-WAN 컨트롤러에 'KeyDrift' 키 탈취 프레임워크

시스코 탈로스가 CVE-2026-20127(Catalyst SD-WAN 컨트롤러 인증 우회, 최고 심각도)을 악용해 KeyDrift라는 맞춤형 악성 프레임워크를 심는 UAT-11473 조직을 확인했다. 표적은 우주·위성 서비스, 방위·항공우주 기술, 정책 연구 기관이다. 탈로스는 이 클러스터가 볼트 타이푼의 은닉 접근망 'Silent Train'과 겹친다고 보지만 확정적 연결은 유보했다.

  • 목적: SD-WAN 컨트롤 플레인 프로세스 내부에서 동작하며, 복호화된 제어 트래픽을 가로채 세션 메타데이터와 데이터플레인 키링 자료를 수집·암호화해 유출한다. 탈로스는 "장기 상시 접근과 자동화된 키 자료 탈취"를 목적으로 설계됐다고 높은 신뢰도로 평가했다.
  • 구성요소: PolyFlame은 정상 vdaemon 프로세스에 주입돼 명령 실행(TinyShell 스타일)·파일 업/다운로드·C2 중계를 담당한다. LittleFilch는 SSL_read를 후킹해 복호화된 제어 메시지를 검사하고, 지정 엣지 노드에서 IP 식별자와 32바이트 AES-256 IPsec 키 자료로 추정되는 필드를 추출한다.
  • 은닉·유출: 수집 데이터는 RSA로 암호화해 /var/tmp/vdaemon.bin에 저장한 뒤 UDP로 공격자에게 전송한다. 두 구성요소 모두 디버깅 방지와 프로세스 위장 기능이 계속 개발되고 있어 초기 버전보다 탐지가 어려워졌다.
  • 대응: CVE-2026-20127은 2026년 2월 패치됐고 UAT-8616이 2023년부터 제로데이로 악용한 이력이 있다. SD-WAN 컨트롤러는 패치 + 시스코 하드닝 가이드를 함께 적용해야 하며, 컨트롤러에서 비정상 vdaemon 재시작·서비스 스크립트 변조·/var/tmp 바이너리를 직접 점검해야 한다.

7. 리눅스 커널 TCP CVE-2026-98432 (CVSS 9.8) — 우분투·RHEL은 아직 미패치

리눅스 커널 TCP 코드의 경쟁 조건(race condition) 취약점 CVE-2026-98432가 커널 CVE 팀 기준 CVSS 9.8로 평가됐다. 우분투·RHEL을 포함한 주요 배포판에 영향을 주며, 10월 29일 기준 우분투와 RHEL은 수정 커널을 내놓지 않았다. 안트로픽은 10월 27일 자사 AI 모델이 이 결함으로 무자격 원격에서 root 권한 명령 실행이 가능한 익스플로잇을 작성했다고 밝혔다.

  • 결함 구조: IPv4 TCP 연결 수립 시 커널이 대기 요청에 저장된 IP 옵션을 복사하지 않고 새 소켓에 넘긴다. 다른 CPU가 재전송된 연결 요청에 응답하려는 사이 소켓이 파괴되면 해제된 메모리를 읽는 UAF가 발생한다. IPv6는 옵션을 복사하므로 영향받지 않는다. 결함은 리눅스 4.4에서 유입됐다.

  • 점수 이견: 커널 팀은 9.8이지만 레드햇·아마존·오라클·SUSE는 5.9~8.1로 낮게 본다. MPTCP(멀티패스 TCP) 리스너가 전제라는 점이 완화 요인으로 작용한 것으로 보이나, 반대로 MPTCP는 애플리케이션이 소켓을 열 때 명시적으로 요청해야 하고 CVE 레코드·수정 커밋에는 MPTCP 언급이 없다는 점도 함께 확인해야 한다.
  • 실무 조치: 롤링 배포판(아치 등)은 10월 초 이후 커널에 업스트림 수정이 포함된 상태이므로 pacman -Syu 후 재부팅으로 정리된다. 반면 우분투 LTS·RHEL 운영 서버는 벤더 패키지가 나올 때까지 대기해야 하며, MPTCP를 쓰지 않는 서버라면 완화 여지가 있지만 근본 해결은 커널 교체다. 재부팅 없이 커널만 올린 서버는 여전히 취약한 커널로 부팅된다는 점을 잊지 말 것.

10. GitHub, npm '설치 시점 방화벽' 공개 프리뷰 — 악성 패키지 설치 전 차단

GitHub가 패키지 방화벽(package firewall)을 공개 프리뷰로 공개했다. npm 패키지 설치 시점에 메타데이터 요청과 패키지 다운로드 양쪽을 검사해 악성 징후가 있으면 설치를 막는 인스톨 타임 정책 게이트로 동작한다. 현재 지원 범위는 npm 패키지에 한정된다.

  • 의미: 기존 SCA·SBOM은 "설치된 뒤 스캔"이라 악성 패키지의 postinstall 스크립트가 이미 실행된 후에야 탐지하는 경우가 많다. 설치 시점 차단은 이 순서를 뒤집는다는 점에서 실질적 개선이다.
  • 한계: npm만 지원하고, 프리뷰 단계이며, 판단 근거는 GitHub의 정책·평판 데이터다. 사내 프라이빗 레지스트리·미러를 쓰는 조직은 정책이 우회될 수 있어 lockfile 고정·출처 검증·설치 스크립트 차단(--ignore-scripts)과 병행해야 한다.
  • 맥락: 같은 날 공개된 조사에서 Hugging Face 악성 모델 3만 2,000회 다운로드, 319개 크롬 확장(1,340만 설치) 검색 하이재킹, 가짜 솔라나 스타터킷이 확인됐다(항목 12). 패키지·모델·확장을 아우르는 설치 시점 통제가 업계 공통 과제로 떠오른 흐름과 맞물린다.

11. 마이크로소프트, Windows 11 KB5127936 프리뷰 배포 — RDP 연결 실패도 수정

마이크로소프트가 Windows 11 25H2·26H2용 누적 프리뷰 KB5127936을 배포했다. 41개 변경이 포함됐고 파일 탐색기와 클라우드(Cloud) 재구축 관련 개선이 중심이다. 별도로 최근 업데이트로 생긴 원격 데스크톱 연결 실패 문제도 해결됐다.

  • RDP 수정: '관리자 보호(Administrator protection)' 보안 기능이 켜진 상태에서 비관리자(non-admin) 사용자가 원격 데스크톱으로 접속하지 못하던 알려진 문제를 마이크로소프트가 해결했다. 재택·원격 지원 환경에서 체감 영향이 큰 결함이었다.
  • 프리뷰의 성격: KB5127936은 선택적(프리뷰) 업데이트로 다음 정기 패치에 통합된다. 운영 환경은 정기 롤업을 기다리되, RDP 이슈로 업무가 막힌 조직은 선적용 판단이 필요하다.
  • 실무 체크: ① RDP 문제 발생 기기에서 관리자 보호 설정과 업데이트 이력 대조 ② 프리뷰 적용 후 파일 탐색기·클라우드 폴더 동기화 회귀 테스트 ③ 다음 정기 패치에서 재적용 여부 확인.
