1. Veeam·Terraform MCP·Django, CVSS 10.0 크로스테넌트 버그 포함 11개 취약점 패치

HashiCorp, Veeam, Django Software Foundation이 Terraform MCP Server, Veeam Service Provider Console, Django 전반에 걸쳐 11개의 취약점을 패치했다. 그중 최고 위험 항목은 CVSS 10.0 만점의 크로스테넌트 버그다.

  • 핵심 취약점: 인증 없이 관리 에이전트 자격증명을 탈취할 수 있는 Veeam 콘솔 결함(CVSS 9.5), 한 사용자의 Terraform 토큰이 다른 사용자에게 재사용되는 HashiCorp MCP 서버 크로스테넌트 결함(CVSS 10.0) 포함
  • 대상: Veeam Service Provider Console, Terraform MCP Server, Django 프레임워크 사용자
  • 대응: 세 공급업체 모두 즉시 업데이트 배포 — 관리형 서비스 제공자(MSP)와 Terraform MCP 사용 환경 우선 적용 권고
  • 시사점: MCP(Machine Control Protocol) 서버와 클라우드 콘솔 같은 인프라 관리 계층이 새로운 공격 표면으로 부상

2. OVSwrap: 리눅스 커널 Open vSwitch 결함으로 로컬 사용자 루트 권한 탈취 가능

리눅스 커널의 Open vSwitch 데이터패스에서 메모리 손상 결함(CVE-2026-64531, CVSS 7.8)이 발견됐다. 일반 로컬 사용자가 광범위한 기본 설정 배포판에서 루트 권한을 얻을 수 있으며, 공개 익스플로잇에는 약 800개 커널 빌드용 사전 구축 레코드가 포함돼 있다.

  • 취약점: Open vSwitch 데이터패스의 메모리 손상 — CVE-2026-64531 (CVSS 7.8), 코드명 OVSwrap
  • 영향: 기본 구성의 다수 리눅스 배포판에서 로컬 권한 상승(LPE)으로 이어질 수 있음
  • 위협: 공개 익스플로잇이 약 800개 커널 빌드용 레코드와 함께 배포되어 실제 악용 가능성 높음
  • 대응: 커널 업데이트 즉시 적용, Open vSwitch 미사용 환경은 모듈 비활성화 고려

3. ClickFix 250+ 도메인, 브라우저 핑거프린팅으로 macOS 악성코드 유도 숨김

250개 이상의 프런트엔드 도메인을 운영하는 macOS 대상 ClickFix 캠페인이 방문자를 핑거프린팅한 뒤 악성코드 유도 화면을 선택적으로 노출하는 방식으로 진화했다. Microsoft Threat Intelligence가 수주간 추적해온 인프라에서 확인됐다.

  • 공격 방식: 서버 측 게이트가 크롤러·샌드박스를 걸러내고, 선별된 Mac 사용자에게만 가짜 소프트웨어 다운로드 화면 표시
  • 피해 규모: 250개 이상의 프런트엔드 도메인, 브라우저 핑거프린팅으로 탐지 회피
  • 대응: 비공식 소프트웨어 다운로드 차단, 클립보드 복사/붙여넣기 명령 실행(ClickFix 수법) 주의
  • 시사점: 사회공학 기반 멀웨어 유도가 타깃팅·회피 기술과 결합해 정교해지는 추세

4. 트로이 목마화된 npm 패키지, 블록체인에서 C2 IP 디코딩하는 NullReceiver 수법 사용

보안 연구진이 블록체인 기반 C2(명령제어) 기법 EtherHiding의 진화형을 발견했다. 완전히 빈 이더리움 전송의 수신 주소 안에 C2 서버 IP를 숨기는 방식으로, "bianira-ui"와 "fluid-type-ui" 두 트로이 목마화된 npm 패키지에서 NullReceiver라는 코드명으로 관찰됐다.

  • 공격 방식: 빈 이더리움 트랜잭션의 수신 주소에 C2 IP를 인코딩하는 dead drop resolver — 탐지 회피에 유리
  • 피해 규모: npm 레지스트리의 악성 패키지 2종 확인 (bianira-ui, fluid-type-ui)
  • 대응: 의존성 검토 및 서드파티 패키지 감사, 레지스트리 무결성 검증 강화
  • 시사점: 공급망 공격이 분산 원장을 인프라로 활용하는 방향으로 고도화
