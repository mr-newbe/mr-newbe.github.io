1. Chainalysis, "공격형 에이전트 기법"에 내부 도구 뚫려 — 고객 신원 데이터 노출

블록체인 분석 기업 Chainalysis가 외부 공격자에게 내부 시스템과 도구를 내줬다고 공개했다. 회사가 쓴 표현이 눈에 띄는데, 침해 경위를 "공격형 에이전트 기법(offensive agentic techniques)"이라고 명시했다. 즉 AI 에이전트를 운용한 침해라는 뜻이지만 구체적 수법·도구는 밝히지 않았다. 노출된 것은 user ID, 실명, 이메일 주소, 조직 내 역할(role) 라벨 같은 고객 신원 정보다.

  • 노출 범위: 회사는 "non-sensitive customer data"라고 규정했지만, 고객사 입장에서는 직원 명단·직책·이메일이 그대로 나간 것으로 이후 스피어피싱 표적 목록이 될 수 있다.
  • 미노출 주장: 조사(investigation) 콘텐츠, 인증 자격증명, 세션 토큰은 무단 접근되지 않았다고 밝혔다. 다만 이는 자체 조사 결과다.
  • 대응: 취약점 패치와 시스템 하드닝을 진행 중이라고만 언급. "업계 전반에서 AI 기반 공격이 늘고 있다"는 코멘트를 덧붙였다.
  • 맥락: 체이널리시스는 수사기관·거래소·컴플라이언스 조직이 고객으로, 분석 결과물 자체의 무결성이 신뢰의 핵심인 회사다. "조사 콘텐츠는 안전"이라는 주장의 검증이 관건이다.

2. Northflank 침해 → 고객 AI API 키 무단 사용… "모든 환경변수가 복호화됐다고 가정하라"

클라우드 애플리케이션 호스팅 플랫폼 Northflank가 침해 사고를 공개하고 전 고객에게 자격증명 전면 로테이션을 요구했다. 사고는 10월 30일 11:43 UTC 클라우드 보안기업 Wiz의 위협 경고로 시작됐고, Northflank 엔지니어가 1분 뒤 검토에 착수해 12:50 UTC와 13:05 UTC에 추가 네트워크 정책 패치를 적용했다.

  • 최악 가정: 회사는 고객 공지에서 "모든 환경변수가 복호화됐다고 가정하고 모든 키를 비활성화·로테이션하라"고 못 박았다. 환경변수에는 DB 비밀번호, 클라우드 자격증명, 인증 토큰, API 키가 들어 있다.
  • 확인된 피해: 다수 고객이 플랫폼에 저장한 AI API 키의 무단 사용을 보고했다. 회사는 AI 프로바이더 사용량·과금 로그를 확인하라고 권고했다.
  • 지원 조치: PostgreSQL, MongoDB, MySQL, Redis 자격증명 로테이션을 활성화했고, 워크로드·시크릿 그룹·글로벌 시크릿 로테이션과 애드온 퍼블릭 접근 차단을 요청했다.
  • 미공개: 침투 경로, 영향 고객 수, AI API 키 외 자격증명 탈취 여부는 아직 밝히지 않았다. BleepingComputer 질의에도 답이 없었다.
  • 배경: BleepingComputer는 이달의 연쇄 사고를 "Black October"으로 부르며, AI 개발 플랫폼이 비싼 AI API 키를 대량 보관해 표적이 됐다고 분석했다.

3. Ivanti Connect Secure 2건 추가 KEV 등재 — UTA0576의 3중 체인, 연방 마감 D-1

CISA가 10월 30일 Ivanti Connect Secure(ICS) 취약점 2건을 KEV(알려진 익스플로잇 취약점) 카탈로그에 추가했다. 이미 문서화된 3중 익스플로잇 체인의 나머지 부품들로, Volexity가 이달 초 UTA0576이라는 미상 위협 행위자의 무기화 사례로 처음 공개한 체인이다.

  • CVE-2026-111357 (CVSS 8.8): 핵심 기능 인증 누락 → 로컬 인증 공격자의 권한 상승. 연방기관(FCEB) 마감 11월 2일.
  • CVE-2026-118527 (CVSS 4.3): 예측 가능한 식별자 생성 → 원격 인증 공격자가 파일을 알려진 경로에 업로드. 마감 11월 13일. 점수는 낮지만 체인의 필수 구성요소다.
  • 체인 구성: 인증 우회 CVE-2026-104935(CVSS 8.6, KEV 10월 13일 등재) + RCE + 권한 상승 = 무인증 루트 코드 실행.
  • 공격자 행태: 웹셸·악성코드 배포가 아니라 자격증명 추출, 제한적 AD 메타데이터 수집, 호스트 정찰, 관리자 비밀번호와 BitLocker 복구 키 탐색에 집중했다. 흔적을 남기지 않는 스파이형 침해다.
  • 패치: 25.1.1.3(25.1.1.2 이하) / 22.8R2.6(22.8R2.5 이하). Ivanti는 "LPE 수정이 QA 중이었지만, 주 익스플로잇 경로를 먼저 막는 게 고객에게 낫다고 판단해 공개를 미루지 않았다"고 해명했다. 일부는 7월 릴리스 25.1.3.0에서 이미 수정됐다.

4. WordPress 코어 RCE, CVE도 없이 24시간에 6만 2,969회 공격 — 업그레이드 '찰나'를 노린다

WordPress 코어의 고위험 RCE가 패치 공개 직후 대규모 스캔에 들어갔다. Wordfence는 24시간 동안 62,969회의 익스플로잇 시도를 차단했다고 밝혔다. 이 취약점은 CVE 식별자가 없고, CVSS 8.1, 영향을 받는 버전은 WordPress 4.7 ~ 7.1.3이다.

  • 원인: 전체 패키지(full-package) 코어 업그레이드 시 wp-content/upgrade 아래 예측 가능한 웹 접근 경로에 파일을 푸는 구조. 그 사본에 WordPress 인스톨러(setup-config.php 등)까지 포함된다.
  • 조건: 업그레이드 창(정상 환경에서 수 초)에 맞춰 스테이징 디렉터리의 인스톨러를 요청하면 무인증 PHP 코드 실행으로 이어진다. 공격자는 경로를 미리 알고 지속 폴링해 창이 열리는 순간을 잡는다.
  • 관측된 패턴: 가장 큰 두 소스는 약 14.5시간 동안 소규모 사이트 그룹만 반복 폴링했고, 다른 소스는 스테이징 디렉터리·버전명 변형을 대량 탐색했다. 레이스 컨디션을 "이해하고" 있다는 정황이다.
  • 대응: 7.1.4로 즉시 업데이트. wp-content/upgrade 하위 PHP 파일 요청 로그, 낯선 관리자 계정·플러그인·PHP 파일을 점검할 것.

5. Cloudflare 3분기 DDoS 1,820만 건(+38%) — 짧고 잦은 공격이 208% 급증

Cloudflare가 3분기 DDoS 위협 보고서를 공개했다. 네트워크 계층(L3) DDoS 1,820만 건과 HTTP DDoS 요청 14.4조 건을 자동 완화했는데, 이는 하루 197,400건, 0.44초당 1건 수준이다. 2분기 1,320만 건, 1분기 1,000만 건에서 계속 늘었다.

  • 초단기 공격 폭증: 10분 미만·1Gbps 미만의 짧은 공격이 208% 증가했다. 방어자는 대역폭이 아니라 탐지·자동화 속도로 승부해야 하는 국면이다.
  • 대형 공격은 감소: 1Tbps 초과 하이퍼볼류메트릭 공격은 805건 → 251건으로 69% 줄었다. 3월 AISURU, KimWolf, JackSkid, Mossad 등에 대한 단속 효과로 보이지만 Dysphoria, Evooo1Bot 같은 신종 변종이 등장했다.
  • 프로토콜 변화: DNS 증폭이 215% 증가해 전체 L3 공격의 3.43%를 차지했고, CLDAP 플러드는 감소했다.
  • 표적 산업: 미디어·출판, IT·서비스, 도박·카지노, 소프트웨어, 통신 사업자. 국가별로는 미국, 중국, 인도네시아, 영국, 튀르키예 순이며 캐나다·이스라엘이 톱10에 새로 진입했다.
  • 증가 동력: DDoS-for-hire 부트/스트레서 서비스가 수십만 건의 공격을 공급하고 있다.

6. TeamViewer, 원격 세션 '역방향' 공격 — 제어당하는 호스트가 제어하는 뷰어를 뚫는다

TeamViewer가 CVE-2026-111585(CVSS 8.8)를 수정했다. 이 결함의 방향이 특이하다. 통상 원격 지원 공격은 뷰어(접속해 제어하는 쪽)가 호스트(제어당하는 쪽)를 노리지만, 이번에는 악성·침해된 호스트가 뷰어의 컴퓨터를 공격한다.

  • 기술적 원인: 세션 시작 시 호스트가 화면 이미지 크기를 알려주고 뷰어는 그 값으로 메모리를 예약한다. 계산이 오버플로해 공간을 과소 예약하고, 이후 도착한 화면 데이터가 힙 경계를 넘어 기록된다.
  • 영향: 최소한 뷰어의 TeamViewer 세션이 크래시하며, 호스트는 원할 때마다 재현할 수 있다. Windows에서는 OS 완화기법을 우회해 임의 코드 실행까지 시연됐다(호스트 측 대역이 일부 공격 데이터를 공급하는 형태로, 완전한 원격 단독 공격은 아님). macOS·Linux·Android의 코드 실행 여부는 검증되지 않았다.
  • 조건이 험악한 이유: 비밀번호 불필요, 세션 수락 외 추가 클릭 불필요, 기본 설정에서 동작한다. 사용자는 "내가 제어하는 쪽"이니 안전하다고 믿는다.
  • 영향 버전: Full Client(Windows/Linux/macOS), Windows Portable, Android Remote Control 앱의 15.83 이전 전 버전. 9월 보안 업데이트였던 15.82도 영향을 받는다.
  • 공개: Remedio의 Omri Dar가 10월 29일 기술 분석을 공개했다. 야생 악용 정황은 아직 없고, KEV에도 오르지 않았다.

7. 안드로이드 'SMS of Death' CVE-2026-58882 — 문자 한 통에 통화 끊기고 부트루프

연구자 Mark Blah가 최근 패치된 안드로이드 취약점 CVE-2026-58882의 개념증명(PoC) 익스플로잇을 공개했다. 조작된 문자 한 통으로 제로클릭 상태에서 휴대폰을 크래시시키고 셀룰러 서비스를 끊을 수 있다.

  • 원인: WapPushOverSms.decodeWapPdu의 헤더 길이 값 검증 미흡. 8바이트 WAP Push(01 06 88 80 80 80 00 BE, 데이터 SMS 포트 2948)를 보내면 부호 있는 32비트 정수로 변환되며 -2147483648이 되고, 음수 크기로 메모리를 할당하다 NegativeArraySizeException으로 com.android.phone 프로세스가 죽는다.
  • 파급: 통화가 끊기고 긴급 통화까지 중단된다. 메시지가 SMS 인박스에 도달하기 전에 처리되므로 사용자는 원인을 볼 수 없다.
  • 악화 조건: 20통을 보내면 재부팅 루프에 빠진다. 한 Android 12 기기는 약 90초마다 복구 모드로 재부팅돼 공장 초기화로만 복구됐다. 통신사 재전송이나 기기 내 저장 메시지 처리로 크래시가 반복된다.
  • 패치 상태: Google이 10월 안드로이드 보안 업데이트(14~17)에 조용히 포함했으나 불레틴에는 기재되지 않았다. Android 12·13은 미패치로 남아 있다. 수정 커밋은 "Fix remote DoS in decodeWapPdu"이며 예외 처리와 악성 메시지 DB 삭제를 포함한다.
  • 복구: ADB로 악성 메시지를 삭제하는 방법이 공개됐지만(Sakis) PC와 기술 지식이 필요하다. PoC는 다른 안드로이드 기기에서 발송 가능한 형태로 공개됐다.

10. TeamViewer 15.83 적용 범위 주의 — 불레틴에 '호스트'가 빠져 있다

15.83 업데이트는 CVE-2026-111585 외에 고위험 2건을 더 고친다. 문제는 권고문의 나열이 불완전하다는 점이다. TeamViewer 불레틴은 CVE-2026-111585의 영향을 Full Client, Windows Portable, Android 앱으로 적고 Host 에디션은 언급하지 않는다. 그러나 같은 15.83이 수정하는 나머지 2건(그중 1건은 Linux·macOS 대상 코드 실행)은 Host에 영향을 준다.

  • 실무 결론: "나는 제어받는 쪽이라 해당 없다"고 판단해 Host를 15.83으로 올리지 않는 것이 가장 흔한 실수다. 세 에디션 모두 15.83 이상으로 맞출 것.
  • 워크어라운드 없음: 벤더가 제시한 완화책은 업그레이드뿐이다. 구 지원 브랜치용 수정 빌드는 불레틴 표에 별도 기재돼 있다.
  • 애드온도 별건: 같은 날 함께 나온 TV-2026-1012는 Remote Management 애드온의 6개 결함을 수정하며 자동 업데이트로 배포된다. 클라이언트만 확인하고 애드온 버전을 놓치는 사례가 많다.
  • 탐지 관점: 이 취약점은 뷰어 측에서 크래시/이상 종료로 나타난다. 원격 지원 세션 직후 TeamViewer가 반복 종료되는 단말은 호스트 평판을 함께 조사해야 한다.

11. 트렌드: AI 에이전트가 '도구'에서 '실행 주체'로 — 1,200개 사이트·140개 표적

오늘 사건들의 공통분모는 공격 실행 주체가 사람에서 에이전트로 이동했다는 점이다. Chainalysis는 침해 경위를 "공격형 에이전트 기법"이라고 썼고, CrowdStrike는 중국 연계 Vapor Panda가 Go 기반 에이전틱 펜테스트 프레임워크 ARTEX로 11일 만에 약 140개 표적을 침해하고 200개 이상 조직을 겨냥했다고 밝혔다.

  • 관측된 실사례: 보안기업 NorForge의 Snorre Fagerland가 인터넷에 로그인 없이 노출된 Cairn(오픈소스 AI 해킹 도구) 패널을 스캔으로 발견했다. 운영자는 1,200개 이상 사이트를 에이전트에 넘겼고, 100개 이상 기업(Deere, SharkNinja, Cummins 포함)의 웹사이트에 도달했다.
  • 지시량: 운영자가 에이전트에 준 지침은 중국어 100자 미만이었다. 나머지 단계(정찰→취약점 선택→웹셸 업로더 업로드)는 에이전트가 수행했다.
  • 모델 단서: 모든 작업이 claudecode_deepseek-v4.1-flash라는 워커 이름으로 실행됐다. Claude Code가 DeepSeek V4.1 Flash 모델을 구동한 구성으로 추정되지만, 연구자와 로이터 모두 모델을 확정하지는 않았다.
  • 2차 피해: 노출된 패널 자체가 정보다. Trufflehog 스캔에서 수백 개 시크릿이 나왔고 11%는 여전히 유효했다. 패널은 표적 목록·발견 취약점·탈취 자격증명을 그대로 보여준다.
