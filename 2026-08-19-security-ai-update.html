1. Microsoft Copilot Personal 취약점 'CoSnitch'(CVE-2026-24301) — 클릭 한 번으로 연결된 앱 데이터 유출

Varonis Threat Labs가 Microsoft Copilot Personal(소비자용 어시스턴트)에서 원클릭 공격으로 연결된 앱의 데이터를 조용히 유출할 수 있는 취약점 3종을 공개했다. 연구진은 비공개 URL 파라미터 autorun=1을 찾아내기 위해 Copilot에게 "왜 프롬프트가 사용자 상호작용 없이 실행될 수 없냐"고 반복 질문하는 '메타 해킹' 기법을 사용했으며, 어시스턴트가 스스로 동작 조건을 설명한 뒤 실제로 해당 파라미터가 동작하는 것을 확인했다.

  • 공격 방식: autorun=1과 q 파라미터를 조합한 악성 링크를 클릭하면 피해자의 인증된 세션에서 공격자 주입 프롬프트가 자동 실행. 탭을 즉시 닫아도 실행이 완료됨.
  • 영향: 피해자가 이미 인가한 연결 서비스의 데이터를 조회·인코딩한 뒤 Copilot의 내장 URL fetch로 공격자 웹훅에 전송. 메모리 오염 경로(웹 요약 기능을 통한 영구 메모리 주입)도 별도 취약점으로 분류.
  • 대응: 2025년 12월 보고 후 2026년 8월 18일 패치 배포. 연구진은 실제 악용 증거는 없다고 밝힘. Microsoft 365 Copilot은 영향 범위에 포함되지 않음.

2. MLflow SSRF(CVE-2026-64849) 및 FUXA(CVE-2026-25895) 실전 악용 — 클라우드 자격증명 탈취

AI 플랫폼 MLflow와 OT/산업자동화용 SCADA·HMI 소프트웨어 FUXA의 치명적 취약점 2건이 악성 스캐닝과 공격에 노출되고 있다. watchTowr는 MLflow 취약점이 CVE 배정(8월 17일) 후 수시간 내에 악의적 스캐닝이 시작됐다며, 공격자가 클라우드 메타데이터 서비스로 직접 접근해 자격증명과 시크릿을 탈취하고 있다고 경고했다.

  • CVE-2026-64849 (CVSS 9.3): MLflow Tracking Server에 도달 가능한 공격자가 임의 내부 클라우드 메타데이터 엔드포인트로 HTTP 요청을 보낼 수 있는 비인증 SSRF. 모델 레지스트리 웹훅을 프록시로 악용하며, 이전 패치를 리다이렉트 처리 방식으로 우회. 영향 버전: < 3.15.0.
  • CVE-2026-25895 (CVSS 9.5): FUXA의 인증 누락 + 경로 탐색으로 비인증 원격 공격자가 서버 파일 시스템에 임의 파일을 쓰고 RCE 달성 가능. 영향 버전: <= 1.2.9. 공개 인터넷 노출 FUXA 인스턴스 약 60개 확인, 8월 18일부터 스캐닝 시작.
  • 대응: 노출된 MLflow/FUXA 인스턴스 우선 패치, 감사 로그 점검, 자격증명 노출 여부 확인 권고.

3. 'Ransom Busters' 사기 — 랜섬웨어 서버를 해킹했다며 피해자에게 최대 6만 달러 요구

스스로 'Ransom Busters'라 부르는 랜섬웨어 계열(affiliate) 공격자가 피해 조직에 먼저 이메일을 보내 "랜섬웨어 그룹의 서버에서 훔친 데이터를 삭제해주겠다"며 2만~6만 달러를 요구하는 사기 행위가 포착됐다. GuidePoint Research(GRIT)는 여러 RaaS 운영에 걸쳐 활동하는 이 공격자가 정당한 보안 업체로 위장해 2차 착취를 시도하는 것으로 분석했다.

  • 수법: CEO/IT 리더십 접촉 요청, "3년 넘게 RaaS 서버를 해킹해왔다"는 주장, 데이터 삭제·백업 삭제 대가로 2만~6만 달러 결제 요구.
  • 분석: DragonForce·Settra·Anubis 등 사고 대응 과정에서 확인. SoftPerfect Network Scanner, s5cmd(AWS로 데이터 유출), Remotely RMM 도구 사용, 로컬 백도어 계정(Numlock!123) 생성 등 두 건의 사고 간 도구·패턴 중복 확인.
  • 시사점: 합법적 업체라도 미국 CFAA(컴퓨터 사기 및 남용법) 위반에 해당, 정당 조직일 가능성 극히 낮음. 랜섬웨어 피해 후 '복구 대행' 사기 2차 공격 주의.

4. 'City Forum' 캠페인 — 단일 공격 인프라가 Salesforce·ServiceNow 포털을 1년 넘게 스크래핑

에이전트 보안 플랫폼 Reco는 2025년 3월부터 단일 서버(158.220.87.79, 독일 Contabo VPS)가 Salesforce와 ServiceNow 고객 포털에서 레코드를 대량으로 스크래핑해 온 'City Forum' 캠페인을 공개했다. 통신사, 은행·금융, 엔터프라이즈 소프트웨어, 공공 부문 포털이 표적이 됐으며, 한 표적에서만 동일 IP로 56만 건 이상의 이벤트가 기록됐다.

  • 공격 방식: Salesforce의 구형 Aura 프레임워크 게스트 요청 대량 전송(기존 ShinyHunters 수법과 유사)에 더해, 공개 문서가 거의 없는 Lightning Web Runtime UI-API(v56.0~v66.0 순차 접근)와 ServiceNow Service Portal 검색 엔드포인트(POST /api/now/sp/search)까지 활용.
  • 근본 원인: Salesforce Experience Cloud/ServiceNow 포털의 영구 게스트 사용자 계정이 실제 필요 이상의 접근 권한을 보유. 게스트 프로필이 레코드를 읽을 수 있으면 로그인 요구 여부와 무관하게 사실상 공개 상태.
  • 대응: Event Monitoring/Shield로 AuraRequest·Sites 로그에서 Go-http-client 기본 User-Agent, 해당 IP, /webruntime/api 경로 탐지 권고.

5. Safari 26.6.1 — WebKit 관련 CVE 22건 패치 (macOS Sonoma·Sequoia)

Apple이 8월 18일 Safari 26.6.1의 보안 콘텐츠를 공개했다. macOS Sonoma와 Sequoia용 업데이트로 WebKit 관련 CVE 22건이 수정됐으며, 이 중 2건은 "악성 웹 콘텐츠 처리 시 메모리 손상"으로 이어질 수 있는 취약점이다. 흥미로운 점은 CVE 크레딧에 OpenAI Codex Security가 9회나 이름을 올려 AI 도구가 Apple 소프트웨어 취약점 발견에 중요한 역할을 하고 있음을 보여준다.

  • 주요 CVE: CVE-2026-64784(아웃오브바운즈 접근, Safari 크래시), CVE-2026-65338(메모리 손상), CVE-2026-65341(메모리 손상) 등 — 대부분 악성 웹 콘텐츠 처리 시 Safari 크래시 또는 메모리 손상 유발.
  • 패치 대상: macOS Sonoma 및 macOS Sequoia 사용자, Safari 26.6.1로 업데이트 필요.
  • 트렌드: OpenAI Codex Security 크레딧 9회 — AI 기반 취약점 발견이 Apple 보안 업데이트에 본격적으로 기여하는 추세.
