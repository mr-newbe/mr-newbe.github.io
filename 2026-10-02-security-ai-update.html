1. KillSec 랜섬웨어 '운영자'는 16세였다 — 스페인에서 체포, 유출 사이트·서버 압수

스페인 경찰이 10대 청소년을 KillSec 랜섬웨어 그룹의 운영자로 체포했다. 독일 함부르크 경찰이 10월 1일 발표한 공동 수사 결과에 따르면, 용의자는 알리칸테(Alicante)주에 거주하는 16세로 KillSec의 실질적 관리자이자 주 운영자로 지목됐다. 9월 30일 하루에 걸쳐 총 3명이 체포됐고, 같은 시점에 그룹의 유출 사이트(leak site)도 당국이 장악했다.

  • 수사 구조: 함부르크 경찰·검찰이 주도하고, 스페인 Guardia Civil과 Mossos d'Esquadra가 집행, Europol·Eurojust가 조정했다. 미국은 FBI 산후안(푸에르토리코) 사무소와 푸에르토리코 검찰이 참여했고, 영국 체포자에 대해서는 푸에르토리코가 범죄인 인도 요청을 냈다.
  • 압수 규모: 서버 5대(본 서버 + 피해자 데이터 보관 서버)와 도메인 5개가 압류됐고, 스페인에서는 컴퓨터·휴대폰·가상자산 지갑을 확보했다. 피해자 몸값 지급과 일치하는 거래가 1차 분석에서 확인됐다. 다른 접근을 막는 과정에서 최소 110테라바이트의 데이터가 보호됐다. 스페인·그리스·영국·루마니아에서 8건의 압수수색이 이뤄졌다.
  • 피해 규모: Europol은 피해자 수를 280명 이상으로 추정하며 "상당한 몸값을 받아냈다"고 밝혔다. 2025년 초 카탈루냐 조직 공격 피해액은 약 100만 유로로 집계됐다. 수사는 2025년 FBI 산후안 사무소와의 공조에서 시작해, 프로필 이미지 단 한 장으로 용의자를 특정했다.
  • 조직 구조: 수사당국은 관리자·개발자·협상자·어필리에이트(외부 파트너) 4개 역할의 용의자를 식별했다. 체포되지 않은 개발자 용의자는 8월에 18세가 됐으며 일부 범행 당시 미성년이었다.
  • 그룹 배경: Rapid7에 따르면 KillSec은 2021년부터 활동한 해커티비스트 그룹이 2023년 10월 랜섬웨어로 전환한 사례로, KillSecurity 2.0·3.0으로 파일을 암호화한다. 함부르크 경찰과 루마니아 DIICOT는 모두 "잠정적" 체포라고 선을 그었다.
  • 시사점: 10대가 관리자로 지목된 RaaS 운영은 진입장벽이 사실상 사라졌다는 뜻이다. 도구·협상·유출 사이트가 서비스로 제공되면 운영 역량은 조직 규모가 아니라 의지만 남는다.

2. MetaMask '진행 중 보안 사고' — 영향받은 이더리움 검증자 사전 탈퇴

MetaMask가 자사 인프라 일부에 영향을 준 "진행 중인 보안 사고(ongoing security incident)"에 대응 중이라고 밝혔다. 지갑 제공사는 "외부 파트너·보안 자문과 협력해 내부적으로 처리하고 있으며, 현재까지 MetaMask 지갑에 대한 즉각적 위협은 발견되지 않았다"고 설명했다. 다만 사고의 성격·원인·영향 범위는 공개하지 않았다.

  • 사전 조치: MetaMask는 비수탁(non-custodial) 스테이킹 운영에서 영향받은 이더리움 검증자를 선제적으로 탈퇴(exit)시키고 있다고 밝혔다. "스테이킹은 비수탁이며, 고객을 대신해 출금 키를 관리하지 않는다"고 강조했다.
  • 제3자 확인: 리퀴드 스테이킹 프로토콜 Lido는 MetaMask가 운영하는 이더리움 검증자와 관련해 고객 자산 보호 조치를 취했다고 확인했다.
  • 시사점: 검증자(validator) 운영은 대량의 키와 자동화된 서명 인프라를 한 곳에 모은다. 지갑 소프트웨어가 안전해도 스테이킹 백엔드가 뚫리면 신뢰의 근거가 흔들린다. "지갑은 안전하다"는 문장과 "무엇이 뚫렸는지는 말할 수 없다"는 문장이 함께 나오는 전형적 초기 대응이다.

3. Warlock 랜섬웨어, 상수도 사업자·통신사 공격 — SharePoint 제로데이 체인으로 침투

중국 연계 위협 그룹 Longlegs(Microsoft 추적명 Storm-2603, 다른 벤더명 GOLD SALEM)가 Warlock 랜섬웨어로 상수도 사업자와 통신 사업자를 공격했다. 포르투갈어·스페인어권 지역의 두 조직이 표적이었고, 공격자는 SharePoint 제로데이 체인으로 초기 침투한 뒤 보안 도구를 무력화하고 수십 대의 호스트를 암호화했다.

  • 침투 경로: Microsoft SharePoint Server 제로데이 연쇄 — CVE-2025-49704, CVE-2025-49706, CVE-2025-53770, CVE-2025-53771(일명 ToolShell 체인)로 초기 접근을 확보했다.
  • 공격 체인: ASPX 웹셸 투입 → 자격증명 탈취(Mimikatz) → PsExec·Impacket/WMI 측면 이동 → 취약한 드라이버를 악용해 보안 도구(EDR)를 무력화 → Warlock 랜섬웨어 배포. 데이터 탈취와 은밀한 웹셸 유지가 핵심이며 이중 갈취를 노린다.
  • 규모: 2025년 6월 러시아어권 범죄 포럼에서 홍보를 시작한 이후, 7월 한 달에만 148개 조직의 400대 이상 SharePoint 서버가 침해됐다. 정부·금융·제조·기술·통신·헬스케어가 주요 표적이며, 초기 공격의 절반가량이 정부 기관이었다.
  • 귀속: Microsoft는 Storm-2603이 중국 기반이라고 '중간 수준 확신'으로 평가한다. Sophos 등은 GOLD SALEM으로 추적하되 국가 배후 단정 근거는 부족하다고 본다 — 귀속은 잠정적으로 취급하고 기술적 탐지·차단에 집중해야 한다.
  • 시사점: 온프레미스 SharePoint는 여전히 가장 값비싼 초기 침투 지점이다. 정부 KEV 목록에서 SharePoint 결함이 반복 등재되는 이유가 여기 있다.

4. WordPress 백도어 'SC', 삭제해도 스스로 재구축된다 — 파일·DB·공유메모리 8곳에 동시 존재

보안업체 Sucuri가 WordPress 침해 사례를 공개했다. 공격자는 최종 페이로드가 사이트를 다시 감염시키지 않고도 계속 살아 돌아오도록 여러 개의 지속성 메커니즘을 심었다. 주입된 흔적의 SC_ 마커를 따 'SC'로 명명된 이 백도어는, Sucuri가 "블록체인으로 제어되는 자기 치유형 메시(self-healing mesh)"라고 부른 구조다.

  • 핵심 설계: "페이로드는 최소 8곳에 동시에 존재하며, 파일·데이터베이스·공유메모리에 흩어져 있고, 그중 어느 하나라도 남아 있으면 나머지 전부를 다시 만들어낸다." 어느 하나를 제거해도 멈추지 않는 순환 구조다.
  • 8개 구성요소: .user.ini(auto_prepend_file로 매 PHP 요청 전 로더 실행), wp-content/db.php(부트스트랩 시 로드, 압축·Base64 페이로드 재배포), advanced-cache.php(다섯 독립 소스에서 플러그인 복원), mu-plugins/hyper-engine-kit.php(실제 멀웨어, MU 플러그인+일반 플러그인 이중 설치), plugins/hyper-engine-kit/(중복 사본), 테마 functions.php(db.php의 쌍둥이), 캐시 디렉터리의 백업본, 랜덤 hex 이름의 ZIP 복원 번들.
  • 지속성의 핵심 — 공유메모리: System V 공유메모리를 지원하는 서버에서는 페이로드가 고정 숫자 키로 식별되는 RAM 세그먼트에 기록된다. RAM에 상주하므로 파일 삭제와 DB 정리 모두를 견딘다. 공유 호스팅에서는 다른 계정이 소유할 수도 있다. 크론 훅(랜덤 이름 + 알려진 fetch 훅)을 등록하며, 시스템 크론은 방문자 트래픽과 무관하게 WordPress 크론 파일을 실행한다.
  • 명령 채널 은닉: C2 통신을 이더리움 블록체인 안에 숨겼다. 합법적 인프라를 악용해 차단·테이크다운을 사실상 불가능하게 만든다.
  • 기능: 관리자 화면·업데이트 검사에서 자신을 숨김, 이더리움 기반 C2 통신, 사이트 핑거프린팅 후 추가 페이로드 수신, 숨은 관리자 계정 생성, 임의 JavaScript 주입(스키머), PHP 코드 실행, 특정 플러그인 비활성화·삭제. 코드에는 읽을 수 있는 함수명이 없고 치환 암호로 난독화돼 있다.
  • 시사점: "현대의 WordPress 감염은 더 이상 파일 하나가 아니라 시스템이다"라는 Sucuri의 표현이 정확하다. 파일 삭제 → DB 정리 → 플러그인 제거 순의 고전적 정화 절차는 이 구조에서 전부 실패한다. 호스트 재구축 또는 재이미징이 유일한 확실한 대응이다.

5. Bitget, 3억 8,750만 달러 탈취 '제3자 제로데이' 공식 확인 — 공격자 맞춤 도구 회수

암호화폐 거래소 Bitget이 지난주 3억 8,750만 달러($387.5M) 탈취 사건이 제3자 보안 제품의 제로데이를 악용한 것이라고 공식 확인했다. SlowMist의 진행 중인 조사 결과를 인용한 발표로, 9월 29일 게시물에서 다룬 '제3자 보안 제품 경유·소액 테스트 후 본공격' 정황이 거래소의 공식 인정으로 확정된 단계다.

  • 확정 내용: 조사에서 제3자 보안 제품과 관련된 악성 활동, 즉 제로데이 취약점이 확인됐고, 공격자가 사용한 맞춤형(customized) 도구를 회수했다. 금액은 $387.5M로 확정됐다.
  • 시사점: 거래소의 방어선이 자사 코드가 아니라 공급망의 보안 제품에서 무너졌다는 점이 핵심이다. "우리 코드는 안전하다"는 보증은 제3자 도구가 제로데이를 갖고 있으면 무의미하다. 보안 제품 자체가 가장 높은 권한으로 동작하는 만큼, 그 제품의 제로데이는 곧 최고 권한 탈취로 이어진다.

10. [트렌드] AI 프런티어의 양면 — 추론 탈취를 막는 쪽과, 가드레일 없이 배포하는 쪽

  • OpenAI — 추론 추출 캠페인 차단: OpenAI는 Moonshot AI(베이징) 연관 인물들이 주도한 조직적 증류(distillation) 캠페인을 식별·차단했다고 밝혔다. 활동은 2026년 7월 1일 시작돼 낮은 볼륨으로 진행되다 7월 24~25일 16,000건의 시도 요청으로 급증했다. OpenAI는 "데이터베이스 침해나 저장된 대화 열람이 아니라, 모델 상호작용을 조작해 보호된 추론이 요청자에게 보이는 형태로 대규모 재현되도록 했다"고 설명했다.

  • Google — Gemini 4 Argon, 방어자 우선 배포: Google은 신형 프런티어 모델 Gemini 4 Argon을 Fairwind 프로그램을 통해 신뢰받는 사이버 방어자에게 배포한다고 발표했다. Gray Swan의 IPI(간접 프롬프트 주입) 벤치마크 1위를 차지했다고 밝혔으며, Argon의 사고 연쇄(chain-of-thought)와 행동을 모니터링해 필요 시 실행을 중단하는 미정렬 완화를 적용했다고 설명했다. 동시에 가드레일 없는 버전 계획도 언급했다.
