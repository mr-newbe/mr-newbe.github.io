1. GitHub Actions 자격증명 탈취 캠페인 ‘GhostAction’ — 오픈소스 메인테이너 2명 계정 장악, 저장소 수만 개에 악성 워크플로

오픈소스 유지관리자 계정 두 개가 탈취돼, 자격증명을 훔치는 악성 GitHub Actions 워크플로가 수만 개 저장소에 주입됐다. StepSecurity는 이를 2025년 9월 처음 드러난 대규모 공급망 공격 GhostAction의 연장선으로 본다.

  • 확산 규모: 18,400 스타의 게임 엔진 pyxel 작성자 Takashi Kitao 계정으로 10월 7일 13:20 UTC부터 27개 저장소에 워크플로가 푸시됐고, 8시간 뒤 Uber athenadriver 원작자 Henry Wu(henrywoo) 계정이 21:10~21:26 UTC 16분 만에 318개 저장소에 같은 워크플로를 밀어 넣었다. Socket은 10월 9일 기준 500개 이상 GitHub 계정이 10월 7일 이후 수만 개 저장소에 커밋한 것으로 집계했다.
  • 공격 방식: 먼저 유지관리자 자격증명(대개 인포스틸러 로그에서 유출된 개인 액세스 토큰, PAT)을 확보한 뒤, 기본 브랜치에 security-audit.yml(표시명 “Security Audit”) 또는 github_actions_security.yml이라는 보안 감사로 위장한 워크플로를 심는다. 이 워크플로는 저장소 시크릿과 작업 트리·전체 git 히스토리의 AWS 키, Anthropic·OpenAI·OpenRouter API 키, GitHub/GitLab 토큰 등을 평문 HTTP로 하드코딩된 IP 193.32.204[.]199로 유출한다.
  • 피해 실적: 이전 웨이브에서 327명의 GitHub 사용자가 운영하는 817개 저장소가 영향받았고 PyPI·npm·DockerHub 토큰 등 3,325건의 시크릿이 유출됐다. GitGuardian은 2026년 8월 31일~9월 30일 사이 373명 사용자/조직의 772개 공개 저장소가 침해됐고, 유출 표적 시크릿이 2,577건(SSH 개인키·Azure·AWS·GCP·Cloudflare·Slack·Discord 봇 토큰 포함)에 달한다고 밝혔다.
  • 2차 위험: henrywoo 네임스페이스의 포크 279개가 각각 악성 워크플로를 품고 있어, Actions가 켜져 있으면 이후 푸시만으로도 자격증명 수집이 재발한다. 유출이 없는 실행에서도 저장소 식별자가 반환되므로, 공격자는 자격증명과 무관하게 ‘실행 가능한 컨텍스트 지도’를 확보한다. 사례 중 하나(2026-08-30, kuafuai/DevOpsGPT)에서는 프로젝트 Docker 이미지에 XMRig 채굴기가 삽입됐다.
  • 대응: 2026년 8월 31일 이후 두 워크플로 파일(security-audit.yml, github_actions_security.yml)이 있는지 저장소 전체 브랜치와 포크를 점검하고, 존재하면 침해로 가정해 GitHub 자격증명·모든 시크릿을 교체하고 워크플로를 삭제해야 한다. 현재까지 탈취한 게시 자격증명으로 악성 패키지가 배포된 사례는 확인되지 않았다.

2. P7 DarkSword iOS 익스플로잇 킷 — 온디바이스 키체인·암호화폐 지갑 탈취와 양방향 C2 추가

iVerify가 기존 DarkSword iOS 익스플로잇 킷의 새로운 변종 P7 DarkSword를 공개했다. “P7”은 공격자가 수정한 코드에서 쓰는 p7_ 변수 접두사에서 따온 이름이다.

  • 변종 특징: 기기 내 흔적을 줄이고, 온디바이스 키체인·암호화폐 지갑 탈취와 공격자 인프라와의 양방향 C2 통신을 새로 추가했다. 기존 변종이 키체인 DB를 복사해 공격자 인프라에서 처리한 것과 달리, 이번 버전은 전화기 안에서 키체인 데이터를 JSON으로 추출한 뒤 유출한다.
  • 체인 구조: 다수의 iOS 취약점을 연쇄해 브라우저 샌드박스를 탈출하고 커널 권한으로 상승시킨 뒤, 페이로드를 SpringBoard 프로세스에 주입한다. 이 임플란트가 공격자 인프라와의 모든 통신을 담당한다.
  • 명령 체계: 15초마다 명령을 폴링하고 하트비트·설치 앱 목록·iCloud 키체인 정보를 보낸다. 응답으로 내려오는 명령에는 execute_command(운영체제 명령 실행), ios_app_data(앱 샌드박스 탐색), wallet_scan·wallet_extract(지갑 앱 탐색·탈취, imToken 등), memo_scan(Apple Notes DB), photo_scan(사진 업로드), sleep/exit가 포함된다.
  • 생태계: Censys는 DarkSword 및 동반 킷 Coruna 관련 컴포넌트가 있는 호스트 5곳의 오픈 디렉터리를 확인했다. 43.134.165[.]205는 두 킷을 합친 DS-Fusion v1.0을 배포하고, 166.88.95[.]90은 C2로 중국 iOS 기기 2대가 3초마다 비콘을 폴링한 기록이 있으며, 운영자 분석 워크스페이스에서는 피해자 복구 구문 11개, 기기 탈취 디렉터리 179개, 리셀러 75계정 명단이 복구됐다. 중국어권 공격자의 ‘착취-서비스(EaaS)’ 형태 운영으로, 금전 동기 공격자 사이로 킷이 확산되는 흐름을 보여준다.

3. AnyDesk 리눅스 사전 인증 RCE(‘AnyPwn’) 완전 익스플로잇 공개 — 연결 승인 전에 루트 권한

연구진이 AnyDesk Linux의 사전 인증 원격 코드 실행 결함에 대한 완전 동작 익스플로잇(‘AnyPwn’)을 공개했다. 누구도 연결을 승인하기 전에 원격에서 루트 권한을 얻을 수 있다. PoC 코드는 10월 8일 GitHub에 게시됐다.

  • 결함 본질: AnyDesk 세션 프로토콜의 힙 버퍼 오버플로다. 할당 끝을 넘겨 인접 힙 객체 필드를 덮어쓰고, ROP 체인으로 임의 명령을 root로 실행한다. V12 보안팀의 Rick de Jager가 코드 리뷰 엔진 V12로 발견했다.
  • 조용한 수정: AnyDesk는 6월 버전 8.0.3에서 수정했지만, 체인지로그에는 “크래시를 유발할 수 있는 버그 수정”으로만 적혔고 CVE도 보안 권고문도 없다. 10월 9일 기준 CVE 미할당, 공식 어드바이저리 미발행. 연구진의 PoC 영상 공개 후 벤더가 8.0.2 빌드를 다운로드 페이지에서 내린 것으로 보인다.
  • 익스플로잇 조건: 직접 TCP 연결(포트 7070)에서만 동작하며 확률적이다 — 힙 레이아웃이 목표 객체를 오버플로 버퍼 옆에 배치해야 하고, 그렇지 않으면 서비스가 크래시한다. 공개된 오프셋은 AnyDesk Linux 8.0.2 특정 빌드 대상이며, 동일 취약 코드 경로는 릴레이 서버 경유로도 도달 가능하나 전체 체인은 Frida 계측으로만 검증됐다. 벤더는 영향 범위를 “리눅스 직접 연결에 한정, Windows·macOS는 영향 없음”으로 밝혔다.
  • 대응: AnyDesk Linux를 최소 8.0.3(최신은 8.1.0) 이상으로 즉시 업데이트한다. 8.0.2 이전 버전도 같은 코드 경로를 공유할 가능성이 제기된다.

7. [취약점] GoBalance 결함 — 공개 정보만으로 .onion 주소 탈취, 다크웹 최대 포럼 Dread 두 주소 장악

다크웹 사이트가 DoS 공격 중에도 접속을 유지하도록 돕는 도구 GoBalance의 결함으로, 누구든 공개 정보만으로 사이트의 .onion 주소를 통제하는 비밀 키를 복원해 주소를 탈취할 수 있게 됐다. Searchlight Cyber가 10월 8일 공개했다.

  • 범위: 주소를 탈취해도 사이트 서버·데이터베이스·저장된 사용자 데이터에 접근하는 것은 아니다. 다만 방문자를 공격자가 통제하는 복제 사이트로 리다이렉트할 수 있다. .onion 주소는 사실상 하나의 공개 키이고, 서명 키가 짧게 유효하더라도 복원된 키로 먼 미래까지 유효한 레코드에 서명할 수 있다.
  • 취약 조건: GoBalance는 Tor의 Onionbalance 로드밸런서를 Go로 재작성한 버전이며, DoS 중 다크웹 사이트 유지에 널리 쓰이는 EndGame 툴킷에 포함된다. 결함은 이 재작성에 있다 — 원본 Onionbalance와 Tor 자체는 영향 없음. 또한 마스터 키를 Tor 자체 키 형식으로 저장한 사이트만 영향받고, GoBalance 설정 도구가 더 안전한 형식으로 키를 쓰는 경우는 노출되지 않는다.
  • 실사례: 다크웹 최대 포럼 중 하나인 Dread의 두 .onion 주소가 10월 5~7일 사이 탈취돼 경쟁 사이트 Conclave로 리다이렉트됐다. 운영자는 처음엔 자체 실수(키 업로드)로 봤으나, 이틀 뒤 백업 주소까지 탈취되자 GoBalance 결함 사용 가능성을 인정했다. Dread는 새 주소로 이전하고 사용자에게 비밀번호 변경을 권고했다.

8. [패치] CISA KEV 5건 — 내일(10/11)이 연방기관 패치 마감일, Flax Typhoon이 실제 악용

CISA가 중국 연계 위협 행위자 Flax Typhoon의 악용을 근거로 결함 5건을 KEV(Known Exploited Vulnerabilities) 카탈로그에 등재했고, 연방기관 대응 마감일은 2026년 10월 11일이다.

  • 등재 5건: CVE-2015-3306 ProFTPD 부적절한 접근 제어(CVSS 10.0, site cpfr/site cpto로 임의 파일 읽기·쓰기) · CVE-2021-3199 ONLYOFFICE Docs 경로 순회(9.8, JWT 사용 시 이미지 업로드 파라미터 /..로 RCE) · CVE-2016-3081 Apache Struts 명령 주입(8.1) · CVE-2015-5477 ISC BIND TKEY 질의 DoS(7.5) · CVE-2023-22894 Strapi 평문 저장(7.2).
  • 공동 권고: 호주·캐나다·일본·뉴질랜드·스페인·영국·미국이 공동 권고를 내고 중국 기반 보안업체 Integrity Technology Group의 활동을 경고했다. 해당 작전은 위 5건 외 3건(Shellshock CVE-2014-6278, Ivanti Pulse CVE-2019-11510, GitLab CVE-2021-22205 — 모두 기존 KEV)을 포함해 8개 결함으로 초기 침투하고, 스캐닝·XSS·Microsoft Exchange 비밀번호 스프레이 후 VPN 소프트웨어로 지속성을 확보하며 이메일·자격증명을 탈취했다.
  • 법 집행: FBI는 Flax Typhoon이 마이크로스캔(MicroScan)·피시허브(FishHub) 해킹 도구를 운영하는 데 쓴 도메인 7개를 압수했다. 두 도구는 중요 인프라 침해에 사용됐다. “중국 정부 연계 행위자는 OT를 포함한 중요 인프라 네트워크에 상주하며 향후 원하는 시점에 핵심 기능을 교란할 목표를 유지한다”(CISA Chris Butera)는 평가가 함께 나왔다.
  • 추가 패치 소식: Microsoft는 지원 종료 버전을 쓰는 기기가 내년 Windows Update 인증서 로테이션 이후 보안 업데이트를 받지 못한다고 경고했다. 지원 종료 OS는 로테이션 전에 업그레이드해야 한다.
