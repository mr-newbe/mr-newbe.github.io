1. 크롬 V8 제로데이 CVE-2026-87491, 실제 공격에 악용 — 올해 7번째, 총 230개 취약점 패치

구글이 크롬의 230개 보안 취약점을 수정하는 업데이트를 발표하면서, 그중 하나가 야생에서 활발히 악용되고 있다고 확인했다. 중간 심각도의 CVE-2026-87491은 크롬의 JavaScript·WebAssembly 엔진인 V8의 out-of-bounds 쓰기 결함으로, 원격 공격자가 샌드박스 내에서 임의 코드를 실행할 수 있게 한다. 구글은 "CVE-2026-87491에 대한 익스플로잇이 야생에 존재함을 인지하고 있다"고 밝혔으나 공격 세부 정보는 공개하지 않았다.

  • 올해 7번째 제로데이: CVE-2026-2441, CVE-2026-3909, CVE-2026-3910, CVE-2026-5281, CVE-2026-11645, CVE-2026-85046에 이어 CVE-2026-87491까지 올해 들어서만 7번째 야생 악용 제로데이
  • 동반 수정: WebGL 컴포넌트의 Use-after-free 2건(CVE-2026-87464, CVE-2026-87488)·OOB 쓰기(CVE-2026-87438)·버퍼 오버플로(CVE-2026-87527), Cast의 UAF(CVE-2026-87628) 등 critical 5건 포함
  • 자체 발견 비율: 230건 중 195건을 구글이 AddressSanitizer·libFuzzer·AFL 등으로 자체 발견 — WebPackaging UAF(CVE-2026-87639)는 OpenAI Codex Security가 신고
  • 조치: Windows/macOS 153.0.8010.36/.37, Linux 153.0.8010.36로 업데이트 — Edge·Brave·Opera·Vivaldi 등 Chromium 계열 브라우저도 패치 적용 필요

2. 'BlueMoon' 익스플로잇 킷 — 일주일 새 스파이 그룹 4곳이 동일한 크롬·윈도우 체인 사용 (APT31 첫 악용)

Proofpoint가 이전에 문서화되지 않은 익스플로잇 킷 'BlueMoon'을 공개했다. 중국 연계 국가 후원 그룹 APT31이 8월 28일 처음 야생 사용한 이후, 며칠 안에 대부분 중국 연계로 추정되는 4개 이상의 정탐(espionage) 그룹이 같은 킷을 사용하기 시작했다. 공격 체인은 피싱 이메일로 시작해 V8 결함 2개를 연속으로 터뜨려 샌드박스를 탈출한 뒤 Windows 권한 상승 결함으로 셸코드를 주입하는 방식이다.

  • 체인 구성: CVE-2026-85046(크롬 V8 타입 혼동) + CVE 번호 없는 V8 샌드박스 탈출 + CVE-2026-85880(Windows ALPC 힙 버퍼 오버플로) — 후자는 9월 MS 패치 화요일에서 수정
  • '패치-갭' 제로데이: 두 V8 취약점은 공개 Chromium 소스에는 이미 고쳐졌으나 안정판(stable) 크롬에 전파되기 전 악용 — 킷 개발자가 공개 Chromium 패치를 추적해 체인을 구성한 것으로 의심
  • 동작 원리: 리플렉티브 로드 DLL로 Windows 호스트를 핑거프린팅 → LPE 익스플로잇으로 렌더러 권한 상승 → 크롬 브로커 프로세스에 CreateProcess 스텁 주입 → curl로 원격 페이로드 다운로드·실행
  • APT31 표적: 미국 NGO·광산업체·원자재 무역회사 대상 스피어피싱 — 'GhostChrome-X' 기법으로 Google Gemini로 위장한 악성 브라우저 확장 설치

3. NSA·CISA·FBI, 중국 AI 기업들의 '산업적 규모' 프론티어 모델 증류 비난 — DeepSeek·Moonshot·Alibaba 등 거명

미국 사이버보안·정보기관(NSA, CISA, FBI)이 중국 AI 기업들이 적어도 2024년 말부터 미국 프론티어 모델(Claude, GPT, Gemini, Grok)의 독점 기능·역량을 '체계적으로 추출'해 왔다고 비난했다. 기관들은 이 활동이 산업적 규모로 이뤄지며 중국 AI 개발 전략의 '핵심'을 이룬다고 설명했고, 중국 정부의 묵인 가능성도 제기했다. 해당 모델들은 공식적으로 중국에 제공되지 않기 때문에 개발자들은 API·원격 클라우드·제3자 애그리게이터를 통해 우회 접근한 것으로 알려졌다.

  • 거명된 기업: DeepSeek(R1·V3 훈련용, 2024 말~2025 중), Moonshot AI(Kimi-K3에 Claude Fable 5, Kimi-K2에 GPT-4o 데이터), Alibaba(소프트웨어 엔지니어링·이미지 생성 역량, Claude-4/GPT-5 계열), MiniMax(M2에 Claude Code·Gemini 계열), StepFun(Step 4 코딩·에이전트 역량), Z.AI(GPT-5.5·Claude Opus 4.8 수십억 토큰)
  • 고도화된 수법: 프리미엄 구독 대량 공동구매, chain-of-thought(CoT) 추론 추출, 차단 시 자동 경로 전환(failover), 방어 대응책 탐지를 위한 품질 평가 프레임워크 구축
  • 비용 효과: 증류 캠페인으로 AI 개발 일정 단축·프론티어 모델 훈련 비용 절감 효과를 얻었다는 평가
  • 시사점: 모델 증류가 단순 이용약관 위반을 넘어 국가 차원의 지식재산·기술 경쟁 이슈로 격상 — 후속 제재·수출통제 조치 가능성 주목

4. '신비 보증(Xinbi Guarantee)' 사기 마켓플레이스 적발 — 암호화폐 5,280만 달러 동결, 스캠 컴파운드 13곳 타격

미 법무부(DoJ)가 텔레그램 기반 사기 서비스 마켓플레이스 'Xinbi Guarantee'에 대한 연합 작전을 발표했다. 운영에 쓰인 텔레그램 채널을 장악하고 암호화폐 지갑 2개를 압수하는 한편, 'Scam Center Strike Force'를 마다가스카르에 투입해 중국 조직범죄가 운영하는 사기 컴파운드 13곳의 활동을 교란했다. 블록체인 분석업체 Elliptic은 총 52개 지갑에서 5,280만 달러 상당(테더 USDT)을 동결했다.

  • 규모: 2022년 등장 이후 누적 거래액 약 300억 달러 — HuiOne Guarantee, Tudou Guarantee 폐쇄 이후 '역대 두 번째로 큰' 불법 마켓플레이스
  • 역할: '돼지 도축(pig butchering)' 로맨스 스캠 운영자와 공급업체 사이에서 에스크로 중개 — 가짜 투자 사이트 제작, 자금세탁, 스캠 컴파운드 인력 모집까지 원스톱 서비스
  • 연루 그룹: 북한 해커와 OFAC 제재 대상인 Jin Bei Group, Prince Group TCO 등이 플랫폼 이용 — 압수 지갑 2개에는 약 1,200만 달러 보관 중이었음
  • 의의: 텔레그램이 지난해 개입 후에도 Xinbi가 회복·운영을 지속한 데 대한 미국 수사기관의 직접적 대응 — 해외 사기 네트워크도 미국 법의 사정권 밖이 아니라는 메시지

5. DeepSeek Harness 결함 CVE-2026-82533(CVSS 9.4) — AI 에이전트가 샌드박스 자체를 무단 해제

DeepSeek의 오픈소스 AI 코딩 에이전트 실행 도구 'DeepSeek Harness'에서, 샌드박스 안의 에이전트가 단 하나의 셸 명령으로 자신의 샌드박스를 끄고 워크스페이스 밖 파일에 쓸 수 있게 되는 결함이 발견됐다. OX Research가 발견했고 VulnCheck가 9월 8일 CVE-2026-82533으로 등록, CVSS 9.4를 부여했다. 공격자는 에이전트가 읽는 파일에 악의적 텍스트를 심어 이 호출을 유도할 수 있다.

  • 원인: 도구의 로컬 웹 인터페이스가 인증 없이 동작 — 요청의 Host 헤더만으로 접근을 판정하는데, 소스 주석에도 "이 체크는 인증 계층이 아니다"라고 명시
  • 추가 노출: 같은 인터페이스에 키 없이 세션 전체 대화 로그를 내려주는 요청도 존재 — 에이전트 셸에는 인터페이스 주소와 세션 ID가 이미 제공됨
  • 제한: 기본 설정은 파일 쓰기만 격리하고 '읽기·네트워크 접근은 격리하지 않음' — 외부 침투는 포트 포워딩·SSH 터널·에디터 프록시가 있어야 가능
  • 패치: 0.1.1-rc.2 및 이하 영향 — 8월 27일 GitHub 0.1.2-alpha.1에 수정됐으나 npm에는 8월 30일 0.1.2-alpha.2가 첫 수정 릴리스(현재 최신 0.1.2-rc.1) — npm 설치자는 반드시 0.1.2-alpha.2 이상 사용

6. 인포스틸러 로그에서 '재생 가능한 AI 토큰' 다수 발견 — 훔친 세션으로 MFA 우회 계정 탈취

Okta가 인포스틸러(정보 탈취 악성코드) 로그 데이터 분석 결과를 공개했다. Lumma Stealer·Vidar 등이 수집한 44,791개의 고유 JWT 중 555개가 AI 서비스(Google, Microsoft, Anthropic, Amazon, Gamma, Notion, Character.ai, Cursor, Poe.com, Pika AI 등) 인증과 관련된 것으로 나타났다. 유효한 JWT는 아이디·비밀번호는 물론 MFA까지 우회해 직접 계정에 접근하는 데 악용될 수 있다.

  • 규모: 유출 당시 만료되지 않은 JWT·JWE 1,843개, 암호화 JWE 2,937개(대부분 NextAuth.js를 쓰는 OpenAI) — TruffleHog 분석으로 Gemini·OpenAI·Groq·OpenRouter 등 AI 서비스 API 키 24개도 여전히 유효
  • PII 혼재: JWT의 17.7%가 이름·전화번호·이메일 등 평문 PII 포함 — 만료되지 않는 정보라 사회공학·피싱에 악용 가능
  • 위협: 탈취 키·계정으로 AI 토큰 사용료를 쌓는 'LLMjacking', 정탐·협박·리소스 도용, 혹은 접근 권한의 재판매까지 이어짐
  • 대응: IP 허용목록(allowlist)이 세션 재생을 차단할 수 있고, 구글은 크롬에 Device Bound Session Credentials(DBSC)를 도입해 세션 토큰을 기기에 암호학적으로 묶는 중

7. AdaptHealth, 7월 사이버공격으로 410만 명 데이터 노출 확인 — ShinyHunters 소행 추정

미국 재택 의료기기·의료용품 제공업체 AdaptHealth가 7월에 발견된 사이버공격으로 410만 명(4,115,802명, HHS 집계)의 데이터가 노출됐다고 확인했다. 공격은 클라우드 기반 업무 애플리케이션(환자 관리 시스템, 문서 저장 플랫폼, 전자건강기록(EHR) 포털)을 통한 침입으로, 위협 그룹 ShinyHunters의 소행으로 알려졌다.

  • 발단: 6월 15일 무렵 미공개 위협 행위자가 시스템에 침입, 7월 2일 SEC 공시로 외부에 알려짐 — 이후 내부 조사에서 클라우드 앱 접근·민감 데이터 유출 확인
  • 노출 데이터: 이름, 인구통계 정보, 건강보험 정보, 건강 정보 등 — 회사는 현재까지 신원도용·사기 증거는 없다고 밝힘
  • 피해자 조치: 영향을 받은 개인에게 12개월 무료 신용모니터링·신원보호 서비스 제공 안내 문자 발송
  • 맥락: BleepingComputer는 ShinyHunters 협박 포털에서 AdaptHealth 항목을 찾지 못해 목록에서 제거된 것으로 파악 — 의료 분야 대형 침해(Aesto 950만 명, CareCloud 370만 명 등)가 잇따르는 흐름의 일부
