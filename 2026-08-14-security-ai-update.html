1. SharePoint 인증 우회(CVE-2026-55040) — 공개 PoC 직후 실전 악용 시작

Rapid7이 공개한 PoC 코드를 공격자들이 즉시 활용하며 Microsoft SharePoint의 치명적 인증 우회 취약점(CVE-2026-55040, CVSS 9.1)에 대한 실전 악용이 관측됐다. 7월 패치 화요일에서 이미 패치된 결함이지만, PoC 공개 후 공격이 급증해 올해 들어 악용된 5번째 SharePoint 취약점이 됐다.

  • 근본 원인: JWT 토큰 검증 파이프라인의 4가지 약점 연쇄 — 'alg: none' 외부 헤더, SharePoint 자체 STS 인증서 지문(x5t) 남용, 신뢰되지 않은 발급자 수용, 서명 미검증으로 비인증 원격 공격자가 유효한 JWT를 위조해 임의 사이트 사용자·관리자로 위장 가능
  • 악용 규모: KEVIntel 텔레메트리 기준 7월 19일 이후 총 12건의 악용 시도 중 8건이 8월 12~13일 PoC 공개 이후에 집중 — 홍콩·일본·네덜란드·대만·미국 등 5개국 8개 IP에서 발생
  • 영향: 인증 우회로 파일 유출·데이터 변조 가능(가용성 영향은 없음). 올해 악용된 다른 SharePoint 결함(CVE-2026-45659, CVE-2026-56164, CVE-2026-58644, CVE-2026-50522)과 함께 SharePoint 인스턴스 최신 패치 유지 필요

2. GeoServer 제로데이 SQL 인젝션 — 공개 수 시간 만에 실전 악용 시도, RCE 가능

오픈소스 지리공간 데이터 플랫폼 GeoServer의 패치되지 않은 제로데이 SQL 인젝션 취약점이 활발한 악용 시도를 맞고 있다. watchTowr는 공개 후 수 시간 만에 수백 건의 악용 시도를 관측했으며, 특정 구성에서는 원격 코드 실행(RCE)까지 이어질 수 있다고 경고했다.

  • 취약점: CVE 미지정 — GeoServer jsonArrayContains의 비인가 SQL 인젝션. 연구자 @q1uf3ng가 8월 12일 X에 공개, 'sa' 데이터베이스 구성에서는 자연스럽게 RCE 달성 가능
  • 현황: 소수의 IP 풀에서 취약 시스템 탐색용 프로빙이 수백 건 발생, 아직 후속 공격 단계는 아니지만 패치 부재로 대규모 악용 전환 가능성 경고
  • 전례: 2024년 GeoServer GeoTools CVE-2024-36401(CVSS 9.8)은 활발히 악용돼 감염 장비가 DDoS·암호화폐 채굴 봇넷 및 리지덴셜 프록시로 전환된 바 있음 — CISA KEV 등재 다수
  • 대응: 노출 인스턴스 식별, 공개 접근 제한, 벤더 패치 모니터링 권고

3. SAP Commerce Cloud 최대 심각도 결함(CVE-2026-58231, CVSS 10.0) — 비인증 원격 코드 실행

SAP가 Commerce Cloud(Data Hub Adapter)의 최대 심각도 취약점을 패치했다. 기본 인증 클라이언트를 남용해 검증이 부족한 특정 함수에 특수 제작된 입력을 전달하면 비인증 공격자가 임의 코드를 실행하고 내부 구성 요소를 손상시킬 수 있다.

  • 취약점: CVE-2026-58231 (CVSS 10.0) — 불충분한 인가 검사·입력 검증으로 인한 RCE, 기밀성·무결성·가용성 모두에 높은 영향
  • 완화: 패치된 Commerce Cloud 릴리스로 업그레이드·재배포, 임시 조치로 IP 필터 세트 구성해 취약 엔드포인트 접근 제한
  • 8월 추가 패치 3건: CVE-2026-44772 (9.9) MII 코드 인젝션, CVE-2026-34265 (9.8) SAP NetWeaver ABAP DIAG 프로토콜 파싱 OOB 쓰기, CVE-2026-44758 (9.1) SSTI·SSRF 연계 명령 실행 — 패치 후 'Secure Transformer'에 허용 호스트 목록 설정 필요

4. Cisco ASA/FTD 결함(CVE-2026-20349) 실전 악용 확인 — 원격 DoS 유발

Cisco가 Secure Firewall ASA·FTD 소프트웨어에 영향을 주는 신규 취약점이 실전 악용되고 있다고 경고했다. HTTP 요청 처리 시 오류 검사 부족으로 비인증 원격 공격자가 Remote Access SSL VPN 서비스에 특수 제작된 요청을 보내 장비를 재시작시켜 서비스 거부(DoS)를 일으킬 수 있다.

  • 취약점: CVE-2026-20349 (CVSS 8.6) — IKEv2 RA VPN(클라이언트 서비스), SSL-VPN(webvpn), ZTNA 구성이 활성화된 장비에 영향
  • 패치: ASA 9.16~9.24 (9.16.4.50, 9.18.4.50, 9.20.4.235, 9.22.3.191, 9.23.1.211, 9.24.1.221) 및 FTD 7.0~10.0 핫픽스 배포 완료
  • 대응: 우회 방법 없음 — 실전 악용이 확인된 만큼 노출된 원격 접속 VPN 서비스는 즉시 패치 적용 필요

5. 악성 LiteLLM 릴리스, Trivy 해킹과 연계 — 2,100개 이상 조직 자격증명 노출 가능성

  • 노출 규모: CloudSEK 공개 조회 도구로 확인 가능, NVIDIA·Cisco·Deloitte·Volkswagen·FedEx·Siemens·X Corp 등 포함 (자격증명 실제 사용 여부는 불명, High/Medium 신뢰도 레이블 제공)
