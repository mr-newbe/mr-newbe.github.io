1. 중국 연계 해커, 신종 랜섬웨어 StormEncryptor 배포 — N-central 취약점 경유 추정

마이크로소프트가 중국 연계 금전 목적 위협 행위자 Storm-1175가 기존에 알려지지 않았던 랜섬웨어 변종 'StormEncryptor'를 배포했다고 공개했다. 이 그룹이 그동안 사용해온 Medusa 랜섬웨어에서의 전환을 의미하며, 초기 침투 경로로 N-able N-central의 신규 취약점 악용이 유력한 것으로 평가된다.

  • 신종 랜섬웨어: C++로 작성, 암호화 파일에 .encrypted 확장자 추가, 모든 스캔 디렉터리에 !!!README_FIRST!!!.txt 랜섬노트 드롭
  • 취약점: CVE-2026-18577 (CVE-2026-18556의 패치 우회) — 인증 우회·계정 탈취, CISA가 활성 악용으로 플래그
  • 그룹 이력: Mirth Connect, ConnectWise ScreenConnect, JetBrains TeamCity, Fortinet FortiClient EMS, Fortra GoAnywhere 취약점 악용 후 Medusa 배포
  • 사후 행동: AnyDesk·SimpleHelp 등 RMM 도구 남용, Advanced IP Scanner로 탐색, Mimikatz로 LSASS 덤프
  • 속도: 초기 접근 → 데이터 탈취 → 랜섬웨어 배포까지 수일 내 완료 — 패치 적용이 시급

4. TrueConf 서버 취약점 체인 악용, 클라이언트 설치파일을 PhantomCore로 교체

위협 행위자 Head Mare가 패치되지 않은 TrueConf 화상회의 서버의 취약점 체인을 다시 무기화해 러시아 계측·전자·운송·에너지·IT 기업을 공격하고 있다. 공격자는 원본 TrueConf 클라이언트 설치 프로그램을 악성 버전으로 교체해 PhantomCore 백도어·RAT를 유포했다고 카스퍼스키가 밝혔다.

  • 취약점: KLCERT-26-057·KLCERT-26-058 — 권한 상승을 동반한 임의 코드 실행, TrueConf 서버 5.3.x~5.3.9, 5.4.x~5.4.9, 5.5.x~5.5.5 및 이전 버전 영향
  • 공격 체인: 기본 개방 포트 TCP 4307 접속 → KLCERT-26-057로 격리 환경 내 스크립트 실행 → KLCERT-26-058로 격리 탈출 → NT AUTHORITY\SYSTEM 권한 획득
  • 지속성: public\js\locale.php를 웹셸로 교체 → TrueConf 데이터베이스 접근 → 클라이언트 배포본에 PhantomCore 주입
  • 이중 백도어: PhantomGraph (SysExcSvc.dll = C2·OneDrive 경유 탈취, SysReadSvc.dll = 명령 파싱·실행) — EDR 탐지 회피 위해 2개 모듈로 분리
  • 추가 행동: SSH 리버스 터널, lsass.exe 메모리 덤프, 시스템 정보 수집
