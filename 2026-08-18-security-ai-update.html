1. GitLab GraphQL 치명적 결함(CVE-2026-19478, CVSS 9.4) — 비인증 공격자가 공개 프로젝트 삭제 가능

GitLab이 자체 관리(Self-Managed) 설치 환경의 CE/EE를 대상으로 한 치명적 취약점을 해결하는 긴급 보안 업데이트를 배포했다. 특정 조건에서 비인증 공격자가 GraphQL 디렉티브를 악용해 공개 프로젝트와 사용자 데이터를 원격으로 수정하거나 삭제할 수 있다.

  • CVE: CVE-2026-19478 (CVSS 9.4, Critical) — 네트워크 경유, 자격증명 불필요, 피해자 조치 없이 악용 가능
  • 영향 버전: 18.2~18.11.10, 19.0~19.0.7, 19.1~19.1.5, 19.2~19.2.3 (18.2~18.10 브랜치는 수정 미포함)
  • 패치: GitLab 19.2.4, 19.1.6, 19.0.8, 18.11.11 — 정기 패치 주기(둘째/넷째 수요일) 밖 긴급 릴리스
  • 추가 결함: CVE-2026-19650 (CVSS 7.1, High) — GraphQL 멀티플렉스 쿼리 핸들러의 CSRF 취약점 (사용자 상호작용 필요)
  • 현황: GitLab.com/Dedicated은 이미 패치 적용, 실전 악용 및 공개 PoC는 아직 확인되지 않음

2. Snowflake GitHub Actions 워크플로우 인젝션 — 조작된 이슈로 내부 Jira 자격증명 탈취 (Wiz)

Wiz 연구진이 Snowflake 공개 저장소(snowflakedb/snowflake-connector-net)의 GitHub Actions 워크플로우에서 명령 인젝션 취약점을 발견했다. 공격자가 조작된 GitHub 이슈를 생성하는 것만으로 내부 Jira API 토큰이 포함된 명령을 워크플로우에서 실행시킬 수 있다.

  • 원인: .github/workflows/jira_issue.yml이 공개 이슈 생성 시 실행되며, 공격자 제어 값(제목/본문)을 shell run 블록에 직접 삽입 + 존재하지 않는 PR 속성 참조로 봇 체크 우회
  • 노출 정보: JIRA_BASE_URL, JIRA_USER_EMAIL, JIRA_API_TOKEN — qa@snowflake.net 소유 토큰으로 보안·컴플라이언스·버그바운티 Jira 프로젝트 읽기 권한 확인
  • AI 각도: Wiz의 Red Agent(자율 공격 에이전트)가 최초 페이로드 문법 오류 후 전략을 바꿔 재시도하며 악용 성공 — GitHub Copilot Autofix 변경분과 연관 추정
  • 대응: 6월 23일 HackerOne 경유 신고 → 당일 PR #1402로 수정(환경변수+jq 인자 전달 방식), Jira 토큰 6월 24일 로테이션, 무단 접근 증거 없음

3. WordPress Forminator 플러그인 치명적 결함(CVE-2026-15748, CVSS 9.8) — 비인증 원격 코드 실행

활성 설치 60만 개 이상의 WordPress 양식 플러그인 Forminator Forms에서 비인증 공격자가 악성 PHP 파일을 포함한 임의 파일을 업로드해 원격 코드 실행(RCE) 및 사이트 완전 장악에 이르게 할 수 있는 취약점이 공개됐다.

  • CVE: CVE-2026-15748 (CVSS 9.8) — handle_file_upload() 함수의 파일 유형 검증 부족, pipe-alternative MIME 키로 위험 확장자 블록리스트 우회
  • 전제 조건: File Upload 필드와 Select 필드를 모두 포함한 양식이 존재해야 악용 가능
  • 영향: 1.56.1 이하 모든 버전 → 1.56.2(7월 31일 배포)에서 해결
  • 악용 시나리오: 커스텀 업로드 저장 경로 사용 시 .htaccess 보호가 생성되지 않아 업로드된 PHP 요청만으로 코드 실행 가능
  • 관련 소식: Wordfence는 최근 User Profile Builder(활성 설치 4만+)의 인증 우회 결함(관리자 ID 1 계정 로그인 가능)도 공개

4. Unisoc VoLTE 영상통화 익스플로잇 체인 — Android 커널 전체 접근 권한 확보 (패치 없음)

SSD Secure Disclosure가 Unisoc 모뎀 펌웨어를 탑재한 기기에서 VoLTE 영상통화를 통한 2단계 익스플로잇 체인을 공개했다. 전체 체인 완성 시 Android 커널 전체에 대한 접근 권한을 얻을 수 있으며, 칩셋 제조사의 수정이 이뤄지지 않은 상태다.

  • 구성: 3월 공개된 SIP 영상통화 RCE(모뎀 레벨 발판) + 신규 권한 상승(CWE-1189, SoC 공유 리소스 격리 부재, CVE 미배정)
  • 영향 칩셋/기기: T606(모토로라 E13), T612(Realme C33), T7250(Xiaomi Redmi A5) 등 최소 3종 — 140개국 이상 판매 기기
  • 악용 조건: 공격자가 제어하는 사설 4G 셀룰러 네트워크 + 피해자가 수신 영상통화에 응답 (오픈소스 4G 코어 네트워크·SDR·특수 SIM으로 PoC 환경 구축)
  • 핵심 원인: 모뎀 프로세서와 앱 프로세서 간 공유 물리 메모리에 하드웨어 경계가 없어 모뎀 컨텍스트에서 커널 메모리 수정 가능
  • 현황: SSD가 이메일/LinkedIn으로 제조사에 연락했으나 응답 없음 — 2026년 2월 패치 모토로라 E13과 2026년 1월 패치 Redmi A5에서 확인

  • CVE: CVE-2026-59310 (CVSS 9.8, 디렉토리 트래버설 → 임의 코드 실행) — Broadcom이 7월 29일 패치 배포
  • 속성 근거: 공격 스크립트 내 중국어 아티팩트, 중국 보안 매체 연구 재사용, UTC+08:00 근무 패턴, 중국 본토 피해 배제 등 (중간 신뢰도)
  • 피해 규모: 공개 5일 후 악용 시작, 47개국 361개 피해 IP — 독일(55)·미국(41)·튀르키예(38)·이란(26)·프랑스(25) 순

6. 신종 리눅스 봇넷 'Evooo1Bot' — 알려진 취약점 악용해 엣지 기기를 SOCKS5 프록시로 전환

Fortinet FortiGuard Labs가 Mirai 봇넷 소스코드 기반의 미발견 리눅스 봇넷 패밀리 'Evooo1Bot'을 발견했다. 인터넷에 노출된 기기들을 장악해 SOCKS 프록시로 전환하며, 2026년 7월부터 실제 활동 중인 것으로 확인됐다.

  • 기능: Mirai DDoS 엔진 재사용 + 암호화된 C2 통신, SSH 무차별 대입 스캐너, SOCKS 릴레이 모듈, 자격증명 스니퍼, 복수 취약점 익스플로잇 무기고
  • 악용 CVE: CVE-2007-3010(Alcatel), CVE-2016-6277(NETGEAR), CVE-2018-14558(Tenda), CVE-2021-46422(Telesquare), CVE-2024-29269(TLR-2005KSH), CVE-2025-55583(D-Link DIR-868L) 등 10개 이상
  • 감염 체인: wget.sh 로더 스크립트 실행 → 아키텍처별 봇넷 바이너리 다운로드 → Bash 히스토리 삭제로 흔적 제거
  • 탐지 회피: 분석 도구·샌드박스·가상환경 탐지 후 C2(포트 443)와 암호화 통신 — HTTPS 트래픽에 섞여 경계 탐지를 우회
