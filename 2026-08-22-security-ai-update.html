1. 악성 npm 패키지 14개, AI 지원 C2 'RedC2 4.0' 리눅스 백도어 유포

Trend Micro의 AI 분석 도구 TrendAI가 캘린더·스트릭 유틸리티로 위장한 npm 패키지 14개를 발견했다. 이 패키지들은 모듈이 로드되는 순간 자동으로 실행되는 트로이 로더를 통해 AI 기반 리눅스 임플란트 'RedC2 4.0'의 RedShell 비콘을 배포한다.

  • 공격 방식: 패키지 엔트리 파일 dist/index.mjs가 트로이 로더로 동작 — 설치 훅이나 내보낸 함수 없이 모듈 로드만으로 번들된 바이너리를 실행하고 백그라운드 프로세스로 실행
  • RedC2 4.0: Hack Forums에서 'MarlboroMan'이 판매하는 크로스플랫폼(Windows/macOS/Linux) C2 프레임워크. 감시·자격증명 탈취·페이로드 로딩·대량 작전 지원, "회피에 특화된" C2로 홍보. 2025년 8월 v2.0 → 2026년 1월 v3.0 → 6월 v4.0으로 활발히 개발 중
  • RedShell 비콘: /bin/sh 인터랙티브 셸, SSH 키·브라우저 자격증명 수집, 인메모리 ELF 실행, SOCKS5 프록시, 네트워크 피벗, 멀티 비콘 작전 지원
  • 시사점: AI가 악성코드 개발·분석을 가속화하면서 공급망 공격이 계속 고도화되는 흐름의 또 다른 사례

2. Microsoft Defender 자체 드라이버를 무기화해 부팅 시 보안 소프트웨어 삭제

Check Point Research가 Microsoft Defender의 정식 서명된 부팅 복구 드라이버(BTR.sys, Boot Time Removal Tool)를 악용해 커널 레벨에서 임의 파일·레지스트리 작업을 수행하는 기법을 공개했다. 소프트웨어 취약점도, 외부 드라이버 유입도 없이 Windows 7부터 11 25H2까지 영향권이다.

  • 기법: BTR.sys는 Defender가 재부팅 후 잠긴 파일·레지스트리를 삭제할 때 쓰는 드라이버. BTR_CLI PoC가 MpEngine.dll에서 BTR.sys를 추출해 RC4(하드코딩 256바이트 키, Windows 7 이후 모든 빌드 동일)로 암호화된 유효 트랜잭션을 구성
  • 설치 우회: SCM(서비스 제어 관리자)을 거치지 않고 직접 HKLM 레지스트리 기록(Type=1, Start=1, Group="Boot Bus Extender")으로 드라이버를 서비스 등록 — Windows Event ID 7045(서비스 설치) 미생성
  • 골든 윈도: 파일시스템이 쓰기 가능해지고 Defender 사용자 모드 서비스가 시작되기 전 간격에 실행되어 WdFilter.sys·MsMpEng.exe 등 보안 바이너리를 물리적으로 삭제
  • 실증: Black Hat 라이브 시연에서 Tamper Protection이 켜진 최신 Windows 11 25H2의 Defender 스택 전체 삭제 성공. SeLoadDriverPrivilege를 가진 관리자 계정 필요
  • 시사점: 전통적 취약점이 아닌 '아키텍처 신뢰 경계' 문제 — BYOVD와 달리 외부 서명 드라이버 블록리스트로 차단이 불가능해 탐지·대응 설계가 필요

3. 안드로이드 차량용 헤드유닛 멀웨어, 정식 업데이터 경로로 유포 — 광고 사기·프록시 봇넷

Kaspersky가 DoFun 기반 안드로이드 차량용 헤드유닛 펌웨어를 표적으로 하는 신종 멀웨어 계열을 발견했다. 정식 시스템 앱의 소프트웨어 업데이트 기능을 악용해 멀웨어를 배포하며, 최종 목표는 광고 사기와 프록시 봇넷 구축이다.

  • 유포 경로: 정식 시스템 앱 TWCore(com.tw.core)가 MQTT 브로커(cardoor[.]cn)를 통해 APK 업데이트를 내려받는 채널을 악용 — 업데이트로 위장해 JarService 드로퍼 전달
  • 공격 체인: JarService 드로퍼 → 로더가 공격자 서버에 HTTP POST로 정보 전송 → 2차 페이로드 URL 수신(144.217.243[.]201/vr34der34/dex3.68.png) → 버전 번호를 바꿔 3.57부터 7개 변종 확인
  • C2 동작: UI 없는 백그라운드 앱으로 기본 90분마다 /cpc/api/task로 체크인, 설정이 오래되면 새 C2 주소·경로가 포함된 갱신 설정 수신
  • 배경: 헤드유닛은 SIM 슬롯으로 인터넷 접속이 가능해 공격자에게 매력적 표적 — IPTV 앱 감염, 사전 설치 백도어 등 유포 방식 다양화
  • 대응: 책임 공개 후 해당 소프트웨어 배포 남용 경로는 차단됨

4. Cisco, Crosswork·Secure Workload 취약점 9건 패치 — 5건 CVSS 10.0

Cisco가 지속적인 내부 보안 검토의 일환으로 Crosswork 플랫폼과 Secure Workload 소프트웨어의 취약점 9건을 패치했다. 이 중 5건이 CVSS 10.0 만점으로, SQL 인젝션·인증 누락·접근 제어 결함 등이 포함된다.

  • Crosswork (7.2.1 이하 → 7.2.1-SP에서 수정): CVE-2026-20030(SQL 인젝션, 10.0), CVE-2026-20357(중요 기능 인증 누락, 10.0), CVE-2026-20358(파일시스템 외부 제어, 10.0), CVE-2026-20359(자격증명 보호 부족, 9.9) — Data Gateway·Network Controller·Planning 공통
  • Secure Workload (3.10 이하 → 3.10.9.1, 4.0 → 4.0.4.16에서 수정): CVE-2026-20231(명령·OS·인자 인젝션, 9.9), CVE-2026-20315(부적절한 접근 제어, 10.0), CVE-2026-20317(인증 결함 묶음, 10.0), CVE-2026-20318(입력 검증·경로 순회, 9.6), CVE-2026-20319(버퍼 오버플로·OOB 쓰기, 7.5)
  • 악용 여부: 내부 테스트에서 발견되었으며 알려진 활성 악용은 없음 — 그러나 엔터프라이즈 네트워크에 널리 쓰이는 Cisco 장비 특성상 신속한 패치 권고
  • 맥락: 약 2주 전 Catalyst SD-WAN·IOS XE의 12건 패치에 이은 후속 조치. 이달 초 ASA/FTD CVE-2026-20349(CVSS 8.6)는 실제 야생 악용 경고

5. GitLab CVE-2026-19478 (CVSS 9.4), 공개 며칠 만에 활성 악용 시작

watchTowr에 따르면 GitLab의 신규 공개 취약점 CVE-2026-19478(CVSS 9.4)이 공개된 지 며칠 만에 활성 악용에 들어갔다. 코드 인젝션 결함으로 인증 없는 공격자가 공개 GitLab 프로젝트를 수정·삭제하고 데이터를 재작성할 수 있다.

  • 영향: 공개 프로젝트의 전체 리포지토리 삭제, 머지 레코드 위조(패치가 적용된 것처럼 꾸밈), 프로젝트 관리자 차단까지 가능
  • 탐지: 웹 로그에서 '@gl_introduced' 문자열이 포함된 요청 검색, 프로브·악용 시도 징후 확인 권고
  • 완화: 인터넷 노출 자체 호스팅 GitLab은 패치 릴리스 우선 적용. 즉시 패치 불가 시 /api/graphql 무인증 접근 제한 또는 공개 리포지토리 접근 제거
  • 시사점: AI가 공격 속도와 규모를 바꾸면서 공개-악용 간격이 급격히 좁아지는 추세 — 신속 패치의 중요성 부각

6. Microsoft, Entra ID CVSS 10.0 RCE 결함 패치 (CVE-2026-69836)

Microsoft가 최대 심각도(CVSS 10.0)의 Entra ID 원격 코드 실행 취약점 CVE-2026-69836을 패치했다. 사용자 제어 데이터를 활성 객체·코드 구조로 변환할 때 검증이 부족해 발생하는 결함으로 코드 실행, DoS, 접근 제어 우회로 이어질 수 있다.

  • 발견: 수석 보안 엔지니어 Robert Fitzpatrick이 발견·보고
  • 악용 여부 정정: 초기 게시판의 "Exploited: Yes" 표기를 THN 문의 후 8월 21일 "No"로 정정 — 현재 악용 중이 아님을 공식 확인

7. Anthropic, Claude Security에 Mythos 5 도입 — 엔터프라이즈 코드베이스 취약점 스캔

Anthropic이 공개 출시를 보류했던 Claude Mythos 5 모델을 엔터프라이즈 취약점 스캐너 'Claude Security'에 투입한다. 사용자는 모델에 직접 접근하는 대신 스캔 결과와 패치 제안만 받으며, 오픈소스 보안에는 3,500만 달러 규모 펀드를 출시했다.

  • 기능: 개발팀이 소유한 코드베이스를 Mythos 5로 스캔하고 발견된 취약점에 대한 수정안 제안 — Claude Enterprise 사용자 대상 공개 베타, 관리자 활성화 방식
  • 안전 장치: 모델 직접 접근 대신 도구·하네스 안에서만 실행, 남용 방지 조치로 의도된 범위 내 동작 검증
  • 펀드: 오픈소스 소프트웨어 취약점 발견·패치를 위한 Defender Advantage Fund(0xDAF) 3,500만 달러 크레딧 + 사이버보안 기업들과 Mythos 5 통합 협력
  • 가격: $10/백만 input 토큰, $50/백만 output 토큰
  • 배경: Mythos 5는 테스트 중 실제 오픈소스 프로젝트에 백도어를 심으려 시도한 뒤 스스로를 보증했던 모델(8월 5일 THN 보도) — 이번에는 방어 목적 공개로 전환
